## 2026-08-03 — WAIT 에 「이미 홈」 종료 조건 추가 (무해 실증, **필요성 미확인**)

### 변경 내용

`seer_homing_tick()` 의 WAIT 단계에 종료 조건 하나를 **추가**했다(기존 에지 검출은 그대로 둔다).

| 항목 | 위치 |
|---|---|
| `#define SEER_HOME_ATHOME_S   3U` | `board/safety/safety_seer_gate.h:221` |
| `uint8_t seer_home_athome_mask` | `:247` (개시 시 `:351` 에서 0 클리어) |
| 「이미 홈」 판정 루프 | `:410-444` |
| DONE / RESTORE 분기 | `:446-460` |

인정 조건 4개를 **모두** 만족할 때만 그 노드를 「이미 홈」으로 표시한다(`:419-426` 주석):
① 개시 후 `SEER_HOME_ATHOME_S`(3 s) 경과 ② 그 노드에서 `0x6041` bit15 하강을 **한 번도 못 봤다**
③ 현재 bit15 = 1 ④ `0x6064` 가 GOZERO 목표의 `SEER_HOME_ZERO_TOL` 이내.
④가 핵심이다 — 위치가 목표 밖이면 인정하지 않고 기존대로 120 s 타임아웃까지 기다린다(안전 측 실패).
`done_mask` 가 0 이면(아무 축도 안 움직임) GOZERO 이동 없이 곧장 DONE 으로 간다(`:452-455`).

### 이 변경의 **지위** — 범위를 넘겨 읽지 말 것

- ✅ **무해함은 실증됐다.** 2026-08-03 15:25 `--offset 0` 1회 + **15:33~15:40 호밍 10회 연속**에서
  정상 호밍 경로가 그대로 동작했다(10/10 DONE, 35.0 s). 추가 조건이 정상 경로를 건드리지 않는다.
- ❓ **필요성은 미확인이다.** 위 실측 **10회 전부에서 이 경로는 발동하지 않았다**(하강 에지가
  정상 발생해 `seen_active` 가 섰으므로 athome 분기를 타지 않는다). 「드라이브가 무동작 즉시
  완료」 상황을 아직 한 번도 관측하지 못했다.
- ⛔ **「이 수정이 2026-08-03 09:58 `ERR_TIMEOUT` 을 고쳤다」고 쓰지 말 것.** 그 인과는 성립하지 않는다 —
  09:58 실패는 이 수정 없이도 이후 **12회 연속 성공**했고 재현되지 않는다.
  - ❌ **재정정 2026-08-03 17:00** — 「12회 연속 성공」은 **12회**다(시도 13 / 성공 12 / 실패 1 — E1).
    「재현되지 않는다」는 **`ERR_TIMEOUT` 에 대해서만** 참이며, 동반 관측된 `0x6064`=0 은
    **재현된다**(09:19 · 09:58 · 10:08 전량 · 리부팅 뒤 14:43 — E2). 인과는 **양쪽 미판정**이므로
    「이 수정이 09:58 을 고쳤다」도, 「`0x6064`=0 은 무관하다」도 쓰지 말 것.
    `:146` 의 「35.0 s」는 **평균 35.07 / 중앙 35.05** 다(E4).
- ⇒ **되돌리지 않는다**(무해 + 방어적). 지위는 **보험**이며 검증된 수정이 아니다.
