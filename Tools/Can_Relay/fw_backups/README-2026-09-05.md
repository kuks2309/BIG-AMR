## 소스 스냅샷 대응

- 추적 파일(`board/safety/safety_seer_gate.h`·`board/usb_comms.h`)의 변경은 커밋 `8dcca83` 이후 **미커밋 diff** 가 원문이다.
- 미추적 파일(`board/main.c`·`board/boards/black.h`)은 각 ADR §Design 에 변경 원문이 보존돼 있다. 저장소 클론만으로는
  이 이미지들을 바이트 동일하게 재현할 수 없다 — 재현하려면 ADR 원문을 두 파일에 재적용해야 한다.
- 앱 영역은 섹터 1~3(0x8004000~0x800FFFF, 49,152 B). **섹터 4(0x8010000)는 보드 이름 레코드**라 어느 플래시 경로도
  지우지 않는다(`Panda.flash_static` 섹터 1~3, DFU 직접 경로 3주소, `PandaDFU.recover` 섹터 0·1).
