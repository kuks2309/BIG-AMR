# 2026-09-03 — 자동 등록에 장착 방향(180° 뒤집힘) 판별 추가

## 무엇을

- `detect_flip_votes(gray)` — 마커 코너 정준 순서(좌상→우상→우하→좌하)에서 위쪽 변
  벡터의 x 부호로 프레임당 방향 득표(True=뒤집힘). 등록 대역 밖 ID 배제.
- `decide_flip(votes, min_votes)` — 카메라 1대 판정(임계·동률 None). 위치가 확정된
  카메라의 방향 불확정은 오류로 등재해 `--apply` 를 차단한다.
- `rewrite_roster_flips(yaml_text, flip_by_name)` — 로스터 `flip:` 줄 표적 갱신
  (True=serial 다음 삽입, False=제거, 주석 보존·멱등).
- 수집 경로(`grab_frames_topics`/`grab_frames_devices`)가 (보드 득표, 방향 득표)
  튜플을 돌려주고, 판정 표에 `방향` 컬럼 추가.

## 왜

사용자 제안(2026-09-03): "카메라 자동인식에 flip 인식도 넣어야 하지 않을까요?" —
마커가 방향 정보를 갖고 있어 위치 판별과 같은 프레임에서 뒤집힘도 판별 가능하다.
T3-1 기체 6대 전부 180° 장착이 실측으로 확인된 직후라, 새 PC 셋업에서 스냅샷 육안
판독 단계를 없앤다.

## 검증

- 단위 테스트 17 PASS(신규 4: 합성 보드 정립/회전 득표, 판정 경계, roster 치환 삽입·제거·멱등)
- T3-1 실보드 E2E(정답 기지 상태): 6대 위치 전부 일치 + 방향 전부 "뒤집힘"(180/180 득표),
  제안 로스터가 수동 설정본과 **현행 동일** 판정 — 판별·치환 멱등성 동시 입증
