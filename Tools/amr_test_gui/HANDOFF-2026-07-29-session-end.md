## 3. 다음 세션이 바로 쓸 사실 (전부 실측)

- **호밍 정의** — 리밋까지 보내 원점을 확립하는 절차이고 `0x6041` bit15 0→1 에서 **끝난다**.
  그 시점에 바퀴는 **리밋에 있다**. 직진 복귀는 호밍의 단계가 아니라 별개의 위치 지령이다.
  Seer 는 `0x607A` 를 노드당 6,464회(≈50 Hz) 상시 스트리밍해 위치 루프가 알아서 되돌린다.
  **우리는 유휴 시 상태 읽기만 하므로 복귀를 1회 명시 지령한다.**
- **탐색 구간에 위치를 얻을 CAN 경로가 없다** — Handbook p.195 위치 객체 3종이 모두 막힌다:
  `0x6064` → 0(표본 1,314/1,445), `0x60FB:02`·`0x60FB:03` → **SDO 무응답**.
  정지 시 `0x60FB:03 slAbsAngle` = `0x6064` = 7,871,817 로 **동일 값**(독립 채널 아님).
  TPDO 0건, 대체 객체(`0x6063`·`0x6062`·`0x60FC`·`0x60F4`·`0x6065`) 전부 ABORT 0x06020000.
  같은 구간에 `0x606C`(−250 rpm)·`0x6078`·`0x6041` 은 **살아 있다**.
- **속도 적분 추정은 탈락** — node3 실제 이동 −3.95° vs 적분 −137.07°(오차 3366%),
  node4 실제 −19.64° vs 적분 +0.00°. `0x606C` 는 조향축 이동량과 대응하지 않는다.
- **판다 freeze 는 우리와 무관** — `seer_is_motion_obj` 로 거른 뒤 `seer_send_bus0` 으로
  **bus 0(Seer)** 에만 합성 응답을 보낸다(`safety_seer_gate.h:76-100`). 우리는 bus 2 다.
- **구동은 지령만으로 돌지 않는다** — 드라이브가 `operation enabled`(상태워드 bit2)여야 한다.
  `drive()` 는 `0x60FF` 만 보내고 조향처럼 `0x6040` 을 동반하지 않아, Seer 가 켜 둔 상태에
  얹혀 동작해 왔다. 2026-07-29 실기에서 실제로 떨어져 **엔코더가 1 count 도 안 움직였다**
  (node1 `0x603F=0x0080` Motor overload alarm). 복구는 `enable_drives()` —
  Fault Reset(bit7 상승엣지) → **fault 가 걷힐 때까지 대기** → `0x06`→`0x07`→`0x0F`.
  **대기 없이 몰아 보내면 `Switch On Disabled`(0x8050)에서 멈춘다**(실측).
- **45° 크랩 node4 결손은 재현되지 않는다** — 가설 5종(상태 차이·bit4 엣지·폴링 과부하·
  점프 크기·프레임 유실)을 실기로 전부 반증, 약 500회 지령 중 0회 재현(debt-016).
  증상은 `wait_settle` 재송신으로 복구된다(A/B 실측: 없음 6 s 미복구 / 있음 0.5 s 정착).

## 6. 다음 세션 주의

1. **전달받은 서술을 1차 자료로 쓰지 말 것.** 이 세션에서 두 번 당했다 — 타 세션이 전한
   "0x6064 는 간헐적 글리치"(실측 반증) · "0x60FB.3 전부 0 리셋"(실제로는 무응답).
   코드·문서에 사실로 적기 전에 **내 측정으로 확인**한다.
2. **정착 판정은 신선도 게이트를 통과해야 한다.** 낡은 실측으로 통과하면 리밋에 있는 바퀴를
   "0° 복귀 확인" 으로 보고한다 — 실제로 그렇게 났다.
3. **호밍 중에도 `0x6041` 을 계속 읽어야 한다.** 조향 위치만 읽도록 바꿨다가 완료 판정을
   깨뜨린 적이 있다(내가 만든 결함).
4. 실기 검증은 **화면**까지 본다. 데이터만 보고 "해결" 이라 보고했다가 GUI 경로에서 다시
   확인해야 했다.
5. `Tools/docking_field_kit` 은 워크트리에 심볼릭 링크로 걸어야 판다 라이브러리가 잡힌다
   (미추적 파일이라 worktree 에 안 딸려온다).
6. **`can_relay` alias 가 이 워크트리를 가리킨다**(2026-07-29 변경, `~/.bashrc`).
   `main` 병합 후 경로를 메인 트리로 되돌릴 것 — 워크트리를 지우면 alias 가 깨진다.
   구 경로는 주석에, 백업은 `~/.bashrc.bak-2026-07-29`.
7. **"구동이 안 된다" 는 신고는 지령이 아니라 상태부터 본다.** `drives_ready()` 로
   `operation enabled` 를 먼저 확인하면 반나절 걸릴 진단이 한 줄로 끝난다.
