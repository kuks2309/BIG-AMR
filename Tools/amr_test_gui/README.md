
`can_relay` 는 `~/.bashrc` 의 alias 다. `DISPLAY` 가 비어 있으면 `:0` 을 쓴다.
이름은 사용자 지정이며, 실행 대상은 CAN relay 도구가 아니라 이 GUI 다.

제어권을 잡기 전에는 조향 지령이 거부된다(로그에 사유 표시).

## 동작 규칙

- **crab 순서** — 조그는 `구동 0 → 조향 지령 → 정착 확인 → 구동` 순이다(`_jog_run`).
  정착은 **두 축(N3·N4) 모두** 허용치 안에 들어와야 통과하며, 실패하면 구동을 취소한다.
- **가동범위 클램프 ±90°** — 실측 검증 범위 밖은 보내지 않는다(`steer_counts`).
  기구 한계는 ±140° 이나 그 값은 Roll_A084 config 이고 본 기체 실측이 아니다.
  범위 밖 지령으로 node4 가 물리적으로 갇힌 사고가 있었다
  ([claude-mistake 2026-07-27-002](../../docs/claude-mistake/2026-07-27-002_node4-unverified-command-damage.md)).
- **단계 램프는 쓰지 않는다** — 시스템의 방식이 아니다. 실기 캡처에서 Seer 는 최종 절대 목표를
  반복 송신할 뿐이고 이동 프로파일은 드라이브가 수행한다
  ([2026-07-28-003](../../docs/claude-mistake/2026-07-28-003_invented-steer-ramp-mechanism.md)).
- **슬라이더는 명령 입력이다** — 실측을 되쓰지 않는다(되먹이면 눈금이 튕겨 먹통이 된다).

## 조향 원점 복귀 (호밍)

조그 패드 아래 버튼. **조향 노드 3·4 에만** 지령한다 — 구동 노드는 기계적 원점이 없다.

| | |

| 시퀀스 | `0x6040=0x86` → `0x6099:00=2500`(250 r/min) → `0x60FB:04=1` (노드당 1회) |
| 완료 판정 | `0x6041` bit15 의 **0→1 전이**. 1 만 보면 이미 호밍된 축을 즉시 완료로 오독한다 |
| 소요 | 실측 약 31초. 개시 확인 10초 · 완료 대기 90초 안에 신호가 없으면 실패로 보고 |
| 금지 | **`0x6098`(homing method)을 쓰지 않는다** — 덮어쓰면 드라이브의 리셋 모드가 꺼진다 |

> ❌ **정정 2026-08-03 15:40** (정본 `docs/homing/2026-08-03-can-relay-homing-assets.md` §0)
>
> - **소요**: 펌웨어 시퀀서 **10회 연속 실측 35.0 s**(34.99~35.16), 그 중 −리밋 탐색 대기가 **31.7 s**.
>   위 「약 31초」는 탐색 구간만 본 값이다. **성공률 10/10**.
> - **`0x6098` 실측값은 `1`**(Home 1 = −리밋 트리거)이다. 「`0x6098`=0 이라 호밍이 비활성」이라는
>   서술은 **폐기**됐다. 「쓰지 않는다(덮어쓰지 않는다)」 규칙 자체는 그대로 유효하다.
> - **리밋 스위치는 실재한다** — 10회 모두 DI(Digital Input) `0x01`→`0x09`(bit3 = −Limit) 전이 관측.
> - **완료 판정 행은 그대로 유효하다** — 홈에 있는 축에 호밍을 걸어도 `bit15` 가 **1→0 으로 떨어진 뒤**
>   31.3 s 만에 −리밋에 닿고 0→1 로 돌아왔다(2026-08-03 15:25 실측). 시작 전 1 을 완료로 읽으면 오판이다.
>   ⚠ 혼동 금지 — **「축이 이미 홈이면 드라이브가 무동작 즉시 완료한다」는 별개 주장이고 폐기됐다**(§0-4).
>   홈에 있어도 축은 리밋까지 실제로 주행한다.
>
> ❌ **재정정 2026-08-03 17:00 (E3·E4)** — 소요는 **평균 35.07 · 중앙 35.05 s**(34.99~35.16).
> **−리밋 탐색(WAIT) 체류는 31.30 s**(평균 31.302 / 중앙 31.295, 31.21~31.38)이고,
> **31.7 s 는 개시(t=0)~RESTORE 절대시각**(평균 31.687)이다 — 둘을 같은 값으로 쓰지 말 것.
> 「성공률 10/10」은 유효하되, 같은 날 호밍 개시는 **총 13회(성공 12 / 실패 1)** 였다(E1).

⚠ **호밍 중 `0x6064` 는 실위치가 아니라 0 을 돌려준다.** 그대로 그리면 바퀴가 0° 로 튀어
실제 자세를 오해하게 되므로, 그 구간에는 각도 갱신을 멈춘다.

⚠ **완료 후 바퀴가 크게 돈다** — 원점(리밋)에서 조향 0° 로 복귀하는 설계된 이동이며
