## 목적 — SIL 폐루프를 닫는 마지막 한 조각

`line_follow` 를 SIL 로 돌리려면 **로봇이 조향한 결과가 오차에 되먹임돼야** 한다. 종전
스모크는 합성 `/line/error` 를 고정값으로 주입했으므로 「조향 부호가 맞는가」까지만 봤고
**「그 조향이 오차를 줄이는가」는 보지 못했다.**

본 노드는 맵 좌표계의 라인을 두고, 플랜트(`translate_sim_odom`)가 만든 로봇 자세로부터
카메라가 볼 오차를 역산해 `/line/error` 를 발행한다. 실제 인식 노드·카메라를 대신한다.

```
translate_sim_odom ─ map→base_link TF ─→ line_sim_sensor ─ /line/error ─→ line_follow
        ↑                                                                      │
        └────────────── /motor/wheel_cmd ← trnav_motion_mux ←──────────────────┘
```

## 무엇을 모사하지 않는가 (정직 선언)

- **인식 자체를 모사하지 않는다** — 검출 실패·오검출·신뢰도 변동·조명은 없다. 기하만 맞다.
- **카메라 투영을 모사하지 않는다** — `half_width_m`(기준행에서 화면 반폭이 덮는 실제 폭)을
  상수로 두고 선형 정규화한다. 렌즈 왜곡·원근은 없다.
- 따라서 이 SIL 은 **제어 수렴성**을 보는 도구이지 인식 성능 시험이 아니다.

## 부호 규약 (제어와 반드시 일치)

- `offset` + = 라인이 **진행방향 기준 오른쪽**. 전방주시점이 라인의 **왼쪽**에 있으면 +
- `angle` + = 라인 위쪽(먼 쪽)이 오른쪽으로 기움 = `진행방향 heading − 라인 heading`
- 후진(`reverse`)이면 진행방향이 `yaw + π` 이며, 라인 방향도 그쪽으로 정렬해 잰다
