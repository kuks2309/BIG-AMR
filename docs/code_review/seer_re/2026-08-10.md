## 3. 함수표 — `seer_param.sh`

셸 스크립트. 파라미터 값을 **실기(API 1400)와 원본 하드(robot.param SQLite) 양쪽에서** 조회해
나란히 출력한다. 두 경로가 어긋나면 그 자체가 신호다(하드 이미지 ≠ 현재 로봇 설정).

| 위치 | 심볼 | 용도 | 인자 → 출력 |
|---|---|---|---|
| `seer_param.sh:18-22` | `HERE`/`REPO`/`SEER_IP`/`AMAP`/`DRIVE_PARAMS` | 스크립트·저장소 위치 · 실기 IP · 접속 래퍼 경로 · 하드 params 경로 | 환경변수 `SEER_IP` 로 덮어씀 |
| `seer_param.sh:25-32` | `DEFAULT_PAIRS` | 기본 조회 세트 — 포트별 동시연결 한도 6종 | `"plugin param label"` 문자열 배열 |
| `seer_param.sh:34-55` | `live_query` | 실기 API 1400 조회 | `plugin param` → `value/default/range/type` 한 줄 |
| `seer_param.sh:57-82` | `drive_query` | 원본 하드 `robot.param` 조회 | `plugin param` 정확 조회, `--grep 조각` 이면 전 플러그인 검색 |
| `seer_param.sh:84-102` | (본문 분기) | 인자 0=기본 세트 / 1=하드 검색 / 2=지정 조회 | — |

**동작 규약**
- `amap_server.sh` 가 없으면 하드 조회만 **건너뛰고 안내**한다(실기 조회는 계속) — graceful.
- 실기 조회 실패도 한 줄 사유만 찍고 종료하지 않는다 — 한쪽만 있어도 값을 얻는 것이 목적.
- 원본 하드는 **읽기 전용**: `/tmp/pcopy` 로 복사 후 `file:…?mode=ro` URI 로 연다(사용자 지시).
- `seer_api` 는 `PYTHONPATH` 로 소스 트리에서 집는다 — colcon install 미소싱 환경에서도 돈다.

## 5. 의존성

- 원격: `amap_server.sh`(선택) → ssh → amap-server 의 `python3`(sqlite3 모듈). 원격에 `sqlite3` CLI 는 없다.
- 로컬: `python3` + 저장소의 `src/Comm/TCP_IP/seer_api`(`SeerApi.get_param`).
