## 대상

`Tools/pc_setup/setup_orin_dev_pc.sh` — Jetson Orin NX(arm64, Ubuntu 22.04) 개발 PC 에
SSH 서버·Tailscale·VSCode 를 설치하는 일회성 셋업 스크립트.
