## 함수표 — `Tools/waypoint_nav/run_route.py`

| 함수 | 위치 | 입력 | 출력 | 용도 | 부작용 |
| --- | --- | --- | --- | --- | --- |
| `load_nodes_smap(path)` | run_route.py:1 | smap 경로 | {이름: (x, y, dir)} | `advancedPointList`(LocationMark) 파싱 | 없음(순수) |
| `load_route(path)` | run_route.py:1 | route yaml | nodes 오버라이드·legs·dock | 레그별 속도 프로파일·heading 모드(turn/keep)·도킹 전환 스펙 | 없음(순수) |
| `RouteRunner` (rclpy Node) | run_route.py:1 | — | — | `/robot_pose` 캐시 + 액션 클라이언트 3종(spin·crab_linear·dock_approach) | 액션 전송 |
| `RouteRunner.run(legs, dock)` | run_route.py:1 | 레그 목록 | 성공 여부 | 레그: heading≠keep 이면 spin(상대각) → crab_linear(현재→노드, target_yaw). 마지막 노드 도착 후 dock 스펙 있으면 `AMRMotionDockApproach` 전송(스테이션 프레임 — map 과 다른 프레임임을 명시). 실패 시 즉시 중단 | 액션 전송 |
| `main()` | run_route.py:1 | CLI(`--smap`·`--route`·`--dry-run`·`--skip-dock`) | exit 코드 | dry-run 은 레그 계획(회전각·거리·속도)만 출력, 액션 0건 | — |

## 검증 기록 (2026-08-24)

- dry-run: 3레그 계획(회전각·거리·속도) 정상 출력
- **SIL 성공**(공유 플랜트 스택 + spin 서버 + 실행기, 무모터): route_sil 3레그
  (전방 4 m·1.0 m/s → 측방 keep·0.5 m/s → 전진 2 m·0.6 m/s) 완주 21 s,
  플랜트 참값 최종 (6.000041, 2.000002) — 목표 대비 **41 µm/2 µm**
- 실행 중 정정 1건: 액션명은 `_abstract` 접미(`amr_motion_crab_linear_abstract`·
  `amr_motion_spin_abstract`) — 서버 소스에서 확정
- 도킹 전환 스펙(dock 섹션)은 dry-run 경로로 확인 — 폐루프 결합은 실기(플랜트가 서로 다름)
- 실기는 mcl2d + `sil_pose_adapter`(`/mcl_pose` 리맵 브리지)로 — **실모터 사용자 승인 후**
