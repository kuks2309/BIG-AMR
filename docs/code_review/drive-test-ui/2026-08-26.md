## 안전 규약

- 호밍 버튼은 확인 다이얼로그(조향 100°+ 스윙 경고) 후 실행.
- 실험 루프는 /robot_pose·액션 서버 부재 시 시작 거부, 중지=goal cancel.
- E-STOP 은 하드웨어 — UI 는 대체하지 않음(탭① 하단 명시).
