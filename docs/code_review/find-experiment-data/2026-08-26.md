# find_experiment_data.sh 인벤토리 (신설 계획)

> 대상: `Tools/find_experiment_data.sh` (bash 단일 스크립트, 비-ROS 도구).
> 목적: "그날 실험 데이터 있나" 질문의 1순위 전수 검색기 — 부재 보고는 본
> 스크립트 0건 출력 첨부 시에만 허용(docs/claude-mistake/2026-08-26-001 재발 방지).

## 함수표

| 함수/블록 | 시그니처 | 용도 | 위치 |
| --- | --- | --- | --- |
| 인자 정규화 | `$1: YYMMDD \| YYYY-MM-DD → D·ISO·NEXT` | 두 날짜 표기를 모두 받아 ISO 구간(그날~익일)으로 변환 | find_experiment_data.sh:12-18 |
| 이름 매치 검색 | find 절 1 | 저장소+홈 전체(-xdev, 깊이 무제한)에서 파일명에 YYMMDD 포함 파일 열거 | find_experiment_data.sh:22-24 |
| 시각 매치 검색 | find 절 2 | 같은 범위에서 그날 생성·수정된 bag(.db3/.mcap/metadata.yaml)·jsonl·csv·html·pdf 열거 | find_experiment_data.sh:26-30 |

## 전역/상수

| 이름 | 값 | 용도 |
| --- | --- | --- |
| `D`·`ISO`·`NEXT` | 날짜 파생 | 이름 매치 토큰·-newermt 구간 |
| `REPO` | 스크립트 상위 | 저장소 루트(어디서 실행해도 동일 범위) |

## 규약

- 깊이·경로 제한 금지(-maxdepth 사용 금지) — 제한 검색의 0건은 부재 근거가 아니다.
- 출력 두 절이 모두 비어야만 "부재" 보고 가능(스크립트가 말미에 명시).
