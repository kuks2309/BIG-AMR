## 수정 계획 (2026-08-28)

- `steer_error_deadband`(기본 0.0 = 종전 동작) 신설 — 감쇠식은 0°부터가 아니라
  불감대 이상 구간에서만 선형: `1 − max(0, err−dead)/(max−dead)`, max 에서 0 유지.
  근거: 순항 리플 실측(bag run_090917) — 측위 잡음발 조향 오차 0.5~1° 에
  1°당 10% 감쇠가 걸려 1.0 m/s 유지 실패. 필터 확대(감도 저하)는 사용자 반려.
