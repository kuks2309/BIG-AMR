## 목적

`/line/error`(`ai_msgs/LineError`)를 소비해 바닥 라인을 추종하는 2WS 액션 서버.
조향각 공간 PD + 커브 감속, 라인 소실 시 조향 유지 coast, 진행 방향 ↔ 카메라 정합 검사.

| 항목 | 결과 |

| 조향 부호 | offset +0.05 · kp 1.2 → 3.44° 기대, **실측 −3.46°**(전진에서 음수 = 우회전) |

| [C] 라인 소실 | 추종 중 `detected=False` → coast 1 s 후 **status −9**, t=2.5 s(소실 1.5 s + coast 1.0 s) |
| [D] 후진 추종 | cam_r · reverse=true → **status 0**, 전륜조향 **+0.00~+3.46°**·속도 **−0.087 m/s** — 전진과 부호만 반전 |

**스모크가 찾아낸 결함 1건(수정 완료)**: goal 사이에 남은 `line_snapshot_` 때문에 시나리오 C 가
시작 즉시 −11 로 죽었다(t=0.0 s). 직전 goal 의 카메라 이름이 캐시에 남아 있었기 때문이다.
`resetLineSnapshot()` 을 execute 진입부에 추가해 이번 goal 동안 도착한 데이터만 쓰게 했다.

**미검증**: 실기 주행. 위는 합성 `/line/error` 입력이며 **실제 조향축·구동축이 붙지 않은**
상태다. 조향 피드백(`wheel_motor_state`)이 없어 `TransientGuard` 의 gate_blocked 경로와
status −8 은 발화하지 않았다. 측위(`/robot_pose`)도 없어 거리 종료(`max_distance`)·
−4/−5/−6 경로 역시 미검증이다. 게인은 원본(2WD 차동) 값이라 이 기체에서 재조정이 필요하다.
