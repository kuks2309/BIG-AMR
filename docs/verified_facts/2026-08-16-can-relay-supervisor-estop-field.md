## 판정

| 주장 | 판정 |
| --- | --- |
| kill → 자동 복귀 전 경로 (병합판) | **실기 PASS** |
| 안정화 창 3 s — RESTORE 직전 보류 | **실기 관측** |
| E-stop 인가 중 복귀 차단(HOLD)·해제 후 복귀 | **실기 PASS** |
| 복귀 계수 창 밖 정리(`prune_stamps`) | **실기 관측** (142 s 간격 → 1/3회 재계수) |
| 수동 해제(IDLE)는 되돌리지 않음 | **실기 PASS** |

## 관측의 한정

- E-stop 재전달을 **1 Hz 상주 발행자**로 재현했다 — 단발 latched 재전달만 있는 환경과는
  타이밍이 다르다. 「첫 진단이 estop 도착을 앞서는」 R3 레이스 자체의 실기 재현은 아니며,
  그 레이스는 SIL(Software In the Loop) 실험 5 가 덮는다. 이번 실기가 보인 것은 재전달이
  안정화 창 안에 도착하면 복귀가 확실히 차단된다는 것이다.
