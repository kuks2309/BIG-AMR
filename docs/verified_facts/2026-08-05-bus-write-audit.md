# 우리가 버스에 쓰는 것 전수 감사 (2026-08-05)

`hold_steer` 가 **매뉴얼·상류·마스터 어디에도 없는 방식**이었음이 드러난 뒤
(`docs/claude-mistake/2026-08-05-001`), 「또 없는 것이 있는가」를 확인하려고
**우리가 CAN 버스에 쓰는 것 전부**를 마스터 캡처와 대조했다.

대조 대상: `Log/homing_capture_220350.jsonl` (마스터 Seer, 180 s, **253,510 프레임**).
우리 값은 **프레임 빌더를 실제로 호출해 디코드**했다(상수를 눈으로 옮기지 않았다).

## 1. 객체 단위 — 12종 중 11종이 마스터와 일치

| 객체 | 이름 | 마스터 송신 | 판정 |
|---|---|---|---|
| `0x6040` | Controlword | 13,144 | ✅ |
| `0x607A` | Target position | 12,928 | ✅ |
| `0x60FF` | Target velocity | 12,720 | ✅ |
| `0x6060` | Modes of operation | 4 | ✅ |
| `0x6081` | Profile velocity | 2 | ✅ |
| `0x6083` | Profile acceleration | 2 | ✅ |
| `0x6084` | Profile deceleration | 2 | ✅ |
| `0x6099` | Homing speed | 2 | ✅ |
| `0x100C` | Guard time | 4 | ✅ |
| `0x100D` | Life factor | 4 | ✅ |
| `0x60FB:4` | RstStart(벤더) | 2 | ✅ |
| **`0x6098`** | **Homing method** | **0** | ⚠ 캡처에 없음 |

**마스터만 쓰고 우리가 안 쓰는 객체는 없다.**

`0x6098` 은 벤더 매뉴얼의 표준 객체(`6098h Homing_method`)이고 상류 `TR_Nav_ros2_ws` 도 쓴다
(`set_current_pos_to_home()`). 다만 **이 기체에서는 이미 기각**돼 있다 —
`config/machine/foil_a082.yaml`: 「method 35 는 이 로봇에서 쓸 수 없다(2026-08-01 실기 기각)」,
설정은 `homing_method: "firmware"`. 즉 살아 있는 경로가 아니다.

## 2. 값 단위 — 28개 전부 일치, 불일치 0건

`drive_init_frames` · `steer_init_frames` · `homing_frames` 가 내는 정적 값을 전수 대조했다.

| 객체 | 우리 값 | 마스터 값 |
|---|---|---|
| `0x6040` | 134 (`0x86`) | 134 (조향축은 63·134) |
| `0x6060` | 구동 **3**(PV) · 조향 **1**(PP) | 동일 |
| `0x100C` / `0x100D` | 500 ms / 1 | 동일 |
| `0x6081` | 30,000 | 동일 |
| `0x6083` / `0x6084` | 250 / 250 | 동일 |
| `0x6099` | 2,500 | 동일 |
| `0x60FB:4` | 1 | 동일 |
| `0x60FF` | 0 | 동일 |

⇒ **debt-017 의 「브링업 값이 맞는가」 부분은 여기서 닫힌다.**
남는 것은 **실기 송신 검증**이다 — `allow_bringup: false` 라 이 프레임들은 아직 나간 적이 없다.

## 3. 이 감사가 덮지 못하는 것 (정직하게)

- **동적 값**은 이 표로 못 본다. `0x607A`(조향 목표)는 별도로 대조했고(마스터 12,928회 중
  95.9% 가 「목표 ≈ 그 시점 실측」), `0x60FF`(구동 속도)는 우리가 mm/s 를 환산해 넣는 값이라
  대조 대상이 다르다.
- **`0x6040` 의 값 분포**는 마스터가 `0x3F`·`0x86` 둘뿐인데(캡처), 우리는 `0x86` 만 쓴다.
  `0x3F` 는 조향 지령 경로(`steer_target_frames`)에서 나가며 그것도 마스터와 같다.
- 이 감사는 **우리가 보내는 것**만 본다. 「보내야 하는데 안 보내는 것」은 다루지 않는다 —
  실제로 그 부류가 있었다(정지 명령 `0x6040=0x03`, 매뉴얼 §PP `:8467-8469`). 채택은 보류 중이다
  (`0x605A` 옵션코드가 4축 모두 **0** 이고 매뉴얼이 그 값의 의미를 정의하지 않는다).
