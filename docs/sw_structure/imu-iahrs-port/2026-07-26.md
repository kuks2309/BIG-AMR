## 잘못된 주석 수정 (2026-07-26)

이식 원본이 TR-AMR 고유 스택을 Big-AMR 인 것처럼 참조하던 주석을 정정(작동 무영향, 재빌드 반영):

- `launch/iahrs_driver.py`
  - `SLAM(hdl_localization/LIO-SAM)` → `SLAM 등 IMU 융합`(TR-AMR SLAM 스택명 제거)
  - `CLAUDE.md 시스템 구성 규칙 참조`(TR-AMR 문서) 제거
  - `LIO-SAM 은 IMU↔LiDAR extrinsic...`(TR 고유) 제거
  - 마운트값을 **"이식 원본(TR-AMR) 실측값, Big-AMR 값 아님"** 으로 명시(debt-002 연계)
  - `tf_translation_z=0.2` 는 `m_bSingle_TF_option=False` 에서 무효(dead)임을 주석화(실제 높이는 static TF `--z`)
- `launch/iahrs_driver_launch.xml`: `CLAUDE.md 시스템 구성 규칙` 문구 제거
- 검증: 설치본 launch 에서 `hdl_localization|LIO-SAM|CLAUDE.md` 잔재 0, 재구동 100 Hz 정상

## 이식 후 확인 필요 (Big-AMR 고유 — 미조정)

원본(TR-AMR) 물리 상수를 그대로 가져왔다. Big-AMR 는 다른 차체이므로 아래는 **재검증 대상**:

1. **base_link→imu_link static TF** — `iahrs_driver.py` 내 실측 마운트 `(-0.37, 0, 0.29)`는 TR-AMR 값.
   Big-AMR 실제 IMU 장착 위치로 재측정·수정 필요. → **기술부채 `debt-002` 등록**(사용자가 나중에 실측 입력 예정).
2. **`interfaces` 패키지명이 범용** — 향후 Big-AMR 다른 커스텀 메시지 패키지와 충돌 위험(현재 충돌 없음).
   사용자 결정: **리네임하지 않고 원본 그대로 유지**(bit-identical 이식 우선). 주의만 유지.
3. **udev serial=="0001"** — CP210x 기본 serial. Big-AMR 에 CP210x 장치가 추가되면 포트경로/serial 로 규칙 분리 필요.
