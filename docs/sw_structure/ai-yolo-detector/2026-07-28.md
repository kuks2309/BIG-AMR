## 목적

Orbbec 카메라 6대의 영상 토픽을 구독해 YOLOv8 로 객체를 탐지하고 결과를 발행한다.
카메라 장치를 직접 열지 않으므로 수집기·내구 시험과 동시 구동이 가능하다.

## 구성

| 패키지 / 파일 | 역할 |
| --- | --- |
| `ai_msgs/msg/Detection.msg` | 검출 1건 (클래스·신뢰도·픽셀 박스) |
| `ai_msgs/msg/DetectionArray.msg` | 프레임 단위 묶음 (+ 추론시간·지연·원본 해상도) |
| `yolo_detector/detection.py` | 변환·스케줄 순수 로직 (ROS·GPU 무의존) |
| `yolo_detector/detector_node.py` | 구독·추론·발행 |
| `yolo_detector/verify_live.py` | 실스트림 검증 도구 (카메라별 갱신률·지연·스냅샷) |
| `launch/detect.launch.py` | 파라미터 노출 |
| `test/test_detection.py` | 단위 테스트 23개 |

`vision_msgs` 를 쓰지 않은 이유: `ros-humble-vision-msgs` 가 이 호스트에 미설치이고 apt 설치에
root 권한이 필요하다(sudo 암호 요구로 불가). 저장소 선례(`trnav_msgs`)를 따라 자체 정의했다.
나중에 `vision_msgs` 를 설치하면 어댑터를 하나 두어 병행할 수 있다.

## 성능 실측 (Jetson Orin NX, 2026-07-28)

### 단일 스트림 순수 추론 (ROS 무관)

| 장치 | 프레임당 | FPS |
| --- | --- | --- |
| **CUDA** | **18.8 ms** | **53.2** |
| CPU | 509.1 ms | 2.0 |

**27배 차이.** CPU 로 떨어지면 실사용이 불가능하므로 노드는 기동 시
`torch.cuda.is_available()` 을 확인해 경고한다.

### 6대 라운드로빈 (통합 검증, 12초)

| 항목 | 값 |
| --- | --- |
| 설정 `total_hz` | 30.0 |
| **실제 총 처리량** | **23.0 Hz** (276회 / 12초) |
| **카메라당** | **3.83 Hz** (6대 전부 46회, **편차 0**) |
| 평균 추론 | 33.7 ms/frame |

**설정값(30 Hz)에 도달하지 못한다** — 추론이 33.7 ms 라 타이머 주기(33.3 ms)를 이미 넘는다.
`per_camera_hz()` 가 계산해 로그에 찍는 "카메라당 5.0 Hz" 는 **이론값이며 실측은 3.83 Hz** 다.
운용자는 로그의 실측 평균(`log_stats`)을 기준으로 판단해야 한다.

⚠ **이 수치는 비관적이었다 — 부분적으로 확인됨.** 위 23.0 Hz 는 소비자까지 같은 executor 에
있던 조건의 값이다. 소비자를 **별도 프로세스**(`verify_live`)로 분리해 다시 재면:

| 조건 | 전체 | 카메라당 | 추론 |
| --- | --- | --- | --- |
| 소비자 동일 프로세스 | 23.0 Hz | 3.83 Hz | 33.7 ms |
| **소비자 별도 프로세스** | **27.3 Hz** | **4.56 Hz** | **24.7 ms** |

발행자(가짜 카메라)는 여전히 탐지 노드와 같은 프로세스이므로, **실카메라(완전 별도 프로세스)에서는
더 오를 여지가 있다 — 재측정 필요**(미실시).

## 설계 결정 4개

1. **라운드로빈 단일 추론** — GPU 는 한 번에 한 프레임이다. 6대에 각자 타이머를 주면 서로
   GPU 를 뺏어 지터가 커진다. 타이머 하나가 한 틱에 한 대씩 처리한다. 실측 편차 0회로 공평성 확인.
2. **구독 콜백은 보관만** — 콜백에서 추론하면 33.7 ms 동안 다른 콜백이 굶는다(ros2-coding.md §2).
3. **기본(단일 스레드) executor** — 콜백·타이머가 직렬이라 `_latest` 에 락이 필요 없다.
   다중 스레드로 바꾸면 **락을 추가해야 한다**(현재 코드가 이 가정에 의존).
4. **클래스는 이름으로 지정** — COCO 의 person 은 0 이지만 자체 학습 모델에서는 번호가 달라진다.
   인덱스를 굳히면 모델 교체 시 조용히 다른 클래스를 본다. 모델에 없는 이름은 기동 시 에러 로그.

## 좌표·시각 규약

- 박스는 **원본 이미지 픽셀**(좌상단 원점). 추론은 `imgsz` 로 축소하지만 발행 전 원복한다.
- `clamp_box` 가 이미지 경계 밖 좌표를 자른다 — 그대로 두면 소비자가 음수 인덱스로 자르다 터진다.
- `header.stamp` 는 **원본 프레임 취득 시각**을 승계한다(추론 완료 시각이 아니다). 검출을 그
  시점의 로봇 자세와 맞출 수 있어야 하기 때문이다. `latency_ms` 로 실제 지연을 별도 보고한다.
