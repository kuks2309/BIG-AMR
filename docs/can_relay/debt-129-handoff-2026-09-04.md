## 1. 이번 세션에 확정·완료된 것 (main 머지: 524c26d)

### 근본 원인 (실측 확정)
**릴레이(K1)가 engage 때 안 끊긴 진짜 이유 = `board/boards/black.h:143` 이 릴레이 구동핀 PC10 을
open-drain 으로 설정.** open-drain 은 HIGH 를 못 내는데, 이 자작 보드 릴레이는 **active-high**
(도면 `Tools/Can_Relay/R02/CAN RELAY R02.pdf`: `PC10→R31(1K)→Q31(2N2222 NPN)→K1 코일→5V`).
→ PC10 이 R33(10K) 풀다운에 눌려 항상 LOW = 릴레이 영영 안 뜸. **하드웨어 결함 아님, 보드 정상.**

### 해결 (재호밍 100%→~13%, ~18/20 PASS)
- **`board/main.c` (git 미추적 — 코드는 `relay-pushpull-open-drain-fix-2026-09-04.md` 에 보존):**
  `SAFETY_SEER_GATE` case → `set_gpio_mode(GPIOC,10,MODE_OUTPUT); set_gpio_output_type(...,PUSH_PULL); set_gpio_output(...,true)` (릴레이 절체).
  `SAFETY_SILENT` case → 같은 push-pull 로 `false` (패스스루).
- **`board/safety/safety_seer_gate.h` (커밋 a33562e·903a9b3):**
  ① pos_act(0x6064) = Seer 명령목표(0x607A) 되돌림 → following error 0.
  ② freeze 시 목표=frozen pos 초기화.
  ③ 조향(node3·4) statusword(0x6041) = **상시 0x9450**(op-enabled+target-reached+homing-attained) — 2슬롯 토글의 0x0050(switch-on-disabled) 순간이 Seer 재init 유발했음.
  ④ (기존) node-guarding 토글 생성, cur/pos 2슬롯 replay.
- 실측: engage 중 모터 bus0 에서 0.5s 후 완전 격리, CAN 오류 40→2, 재호밍 100%(0/4)→~13%(누적 14/16·4/4).

## 2. ⚠ 다음 세션 필독 — delicate 상호작용 (삽질 방지)

- **`usb_comms.h` 0xe8 핸들러의 `set_intercept_relay(wValue)` 는 릴레이 cut 에 필수.**
  이번 세션에 "PC10 은 set_safety_mode 에서 직접 제어하니 0xe8 의 set_intercept_relay 는 불필요" 가설로
  제거했더니 **cut 이 깨져 0/8 재호밍**. 원복함. → **set_safety_mode 의 PC10 push-pull HIGH _단독_으로는 부족**,
  0xe8 의 set_intercept_relay 와 **함께** 작동함(정확한 상호작용 미규명). **섣불리 건드리지 말 것.**
- release cover: `rig.release()` 가 `0xe8=0` 을 보내지만 펌웨어 0xe8 은 wValue 무시하고 cover 무조건 arm →
  반환 후 300ms emulate 활성인데 relay 는 SILENT 로 열림(모터 복귀) → 그 창의 충돌이 잔여 재호밍 후보.
  단 0xe8 을 고치면(위) cut 이 깨지므로, **cover 만 분리해 끄는 방법**(set_intercept_relay 는 유지)이 필요.

## 3. 잔여 ~13% (다음 세션 과제)

- **증상:** 간헐(약 1/8~2/8) release 시 조향 137° 스윙. PASS/FAIL 회차의 Seer 명령 동일(cw=0x86·hspd·v60FB 매번) → 명령 차이 아닌 **타이밍/레이스**.
- **후보 접근:**
  1. **seamless disengage** — 반환 전이에서 relay 를 cover 창 동안 닫아둔 채 emulate 로 덮고 그 뒤 열기. (0xe8 cover 를 set_intercept_relay 와 분리해 제어; ADR `docs/adr/2026-09-03-disengage-handover-restore.md`)
  2. **CiA402 homing-attained** — Seer 재init/homing 명령에 statusword 상태전이로 응답(현 상시-0x9450 로 부분 달성).
- **권장 진단:** release 전후 bus0 를 μs 타임스탬프로 캡처해 Seer 가 언제/무엇으로 스윙을 개시하는지, cover 창 충돌 유무를 확정.
