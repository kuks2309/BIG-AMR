# 2026-07-29 08:00 (KST) — 다른 마스터의 관측을 우리 폴링 경로로 전이해 각도 표시를 동결

## 무엇을 했는가

호밍 구간에서 바퀴 각도 표시를 **통째로 멈추는** 가드를 유지하고, 리팩터 중에는 그것을
`_pos_frozen` 이라는 이름의 전용 플래그로 **더 정교하게 만들기까지** 했다. 근거로 든 것은
1차 캡처 `Log/homing_capture_220350.jsonl` 이었고, 코드·README·ADR·mistake entry 에
반복해서 이렇게 적었다:

> "호밍 중 `0x6064` 는 실위치가 아니라 0 을 돌려준다 — 그대로 그리면 바퀴가 0° 로 튄다"

## 무엇이 잘못이었나

인용한 캡처는 정확했다. 그 구간 3,105/3,105 표본이 전부 0 이었음을 전수로 확인했다.
**잘못은 그 위에 세운 가드가 실값까지 함께 버린 것이다.**

우리 폴링 경로에서 직접 측정한 결과(2026-07-29, intercept 보유):

| 구간 | `0x6064` |
| --- | --- |
| 리밋 탐색 (~31 s) | **0 만 온다** — 표본 1,363(node3)/1,368(node4) 전부 0 |
| 리밋 도달 시점 | 실값 (node3 −137.27°) |
| 조향 0° 복귀 (~3 s) | **실값 연속** — −130.57 → −106.23 → −77.68 → −48.63 → −20.70° |

즉 탐색 구간에 0 만 온다는 것은 우리 경로에서도 사실이다. 그러나 **리밋 도달 판독과
137° 복귀 스윙은 실값이 나오는데**, 호밍 전 구간을 통째로 동결하는 가드가 그것까지 버렸다.
운전자가 가장 봐야 할 큰 이동이 화면에서 사라진 것이 결함이다.

⚠ **정정 (같은 날, 본 entry 자체의 오염)**: 본 entry 최초 작성 시 "탐색 중에도 `0x6064` 는
실제 엔코더 값을 계속 보고하고 0 은 간헐적 글리치" 라고 적었다. **그것은 내 측정이 아니라
전달받은 서술을 그대로 옮긴 것이고, 이후 내 실측 2회가 반증했다**(위 표). 검증 없이 옮겨
적어 README·코드 주석까지 오염시켰다 — 이 entry 를 쓰면서 같은 종류의 잘못을 반복했다.

## 사용자 지적

> "0x6064 는 호밍 중에도 실제 엔코더 값을 계속 보고합니다 — 문서가 말한 '호밍 중 0 지속'이
> 아닙니다. 0 은 지속이 아니라 간헐적 글리치입니다."
> "GUI 는 호밍 중 표시를 통째로 끄지 말고, 0/글리치만 필터하면 각도가 나옵니다.
> 현재 `not self._homing` 가드가 과보수적입니다."
> "호밍중 각도 실시간 반영 안되는 것 보완"

## 원인 분석

`verify-skip` 계열(2026-07-29-001·002)과 뿌리가 다르다. 이번엔 **검증을 했고 인용도
정확했다** — 캡처를 직접 파싱했고 숫자도 맞았다. 실패는 **관측의 유효 범위를 좁히지 않은 것**
이다. 측정에는 언제나 조건이 붙는데(누가 폴링했는가·게이트가 어떤 상태였는가) 그 조건을
결론에서 떼어내고 장치의 항구적 성질로 승격시켰다.

증거를 더 세게 확인할수록(전수 3,105건) 결론이 더 단단해 **보이는** 것이 함정이었다.
표본 수는 **같은 조건 안에서만** 신뢰도를 올린다 — 조건 밖으로는 한 발짝도 옮겨주지 않는다.

부수적으로, 이 잘못된 전제 위에 **코드를 더 정교하게 쌓았다.** 리팩터 중 `homing` 인터록과
판독 동결을 `_pos_frozen` 으로 분리하며 "복귀 이동이 화면에 그려지도록 개선했다" 고 보고했다.
전제가 틀렸으므로 그 정교화는 결함을 더 정밀하게 구현한 것이었다.

## 재발 방지

- **구현 수정 (1) 통째 동결 제거** — `decode_frames` 가 **정확히 0 인 표본만** 버린다.
  0 은 실위치가 아니고(우리 프레임에서 −137.27°), 리밋에 실제로 있을 때의 판독은 596·543
  처럼 0 이 아니다.
- **구현 수정 (2) 호밍 중 집중 폴링** — 실값이 드물게 섞이므로 폴링이 느리면 그 표본을
  통째로 놓친다. 호밍 중에는 조향축 `0x6064` 만 고속으로 읽는다(`_loop`).
  **실측 효과**: 137° 복귀 스윙이 0.5 s 간격으로 −130.57→−20.70° 로 추종된다(이전 0건).
- **회귀** — `test_homing.py` 3건: 0 표본 폐기 / `homing=True` 인 동안에도 실측 반영 /
  간헐 0 이 직전 실측을 덮어쓰지 않음.
- **남은 사실 그대로 기록** — 탐색 구간(~31 s)은 드라이브가 0 만 돌려주므로 **표시가
  멈춘다.** 이는 장치 동작이며 GUI 로 해결할 수 없다. `debt-017` 에 측정치와 함께 남겼다.
- **인용 규칙** — 실기 관측은 측정 조건(누가 폴링했는가·게이트 상태)을 결론에 붙여 적고,
  다른 경로에 적용하려면 **그 경로에서 다시 측정**한다. 표본 수는 조건 밖으로 결론을
  옮겨주지 않는다. **전달받은 서술은 1차 자료가 아니다 — 내 측정으로 확인하기 전에는
  코드·문서에 사실로 적지 않는다.**
