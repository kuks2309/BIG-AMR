# 2026-07-29 08:00 (KST) — 다른 마스터의 관측을 우리 폴링 경로로 전이해 각도 표시를 동결

## 무엇을 했는가

호밍 구간에서 바퀴 각도 표시를 **통째로 멈추는** 가드를 유지하고, 리팩터 중에는 그것을
`_pos_frozen` 이라는 이름의 전용 플래그로 **더 정교하게 만들기까지** 했다. 근거로 든 것은
1차 캡처 `Log/homing_capture_220350.jsonl` 이었고, 코드·README·ADR·mistake entry 에
반복해서 이렇게 적었다:

> "호밍 중 `0x6064` 는 실위치가 아니라 0 을 돌려준다 — 그대로 그리면 바퀴가 0° 로 튄다"

## 무엇이 잘못이었나

인용한 캡처는 정확했다. 그 구간 3,105/3,105 표본이 전부 0 이었음을 전수로 확인했다.
**잘못은 그 성질을 우리 경로로 옮긴 것이다.**

| | 2026-07-27 캡처 | 우리 GUI |
| --- | --- | --- |
| 호밍 주체 | Seer | 우리 |
| 판다 | **수동청취**(송신 0) | **intercept 보유** |
| 관측한 `0x6064` | **Seer 의 폴링에 대한 응답** | **우리 폴링에 대한 응답** |

두 경로는 마스터도 게이트 상태도 다르다. 그럼에도 "호밍 중 0x6064 = 0" 을 **경로 무관한
장치 성질**로 일반화했다. 사용자 실기 측정이 반증했다 — 우리 폴링에서는 탐색 중에도 실제
엔코더 값이 계속 오고(node3 7,871,817 / node4 7,840,084 대다수), 정확한 0 은 **간헐적으로만**
섞인다.

결과로 GUI 는 호밍 31초 동안 바퀴 각도를 **멈춰 세웠다.** 운전자가 가장 보고 싶은 구간
(100° 넘게 도는 스윙)에서 화면이 얼어 있었고, 그것을 "설계된 안전 동작" 이라고 문서에 적었다.

## 사용자 지적

> "0x6064 는 호밍 중에도 실제 엔코더 값을 계속 보고합니다 — 문서가 말한 '호밍 중 0 지속'이
> 아닙니다. 0 은 지속이 아니라 간헐적 글리치입니다."
> "GUI 는 호밍 중 표시를 통째로 끄지 말고, 0/글리치만 필터하면 각도가 나옵니다.
> 현재 `not self._homing` 가드가 과보수적입니다."
> "호밍중 각도 실시간 반영 안되는 것 보완"

## 원인 분석

`verify-skip` 계열(2026-07-29-001·002)과 뿌리가 다르다. 이번엔 **검증을 했고 인용도
정확했다** — 캡처를 직접 파싱했고 숫자도 맞았다. 실패는 **관측의 유효 범위를 좁히지 않은 것**
이다. 측정에는 언제나 조건이 붙는데(누가 폴링했는가·게이트가 어떤 상태였는가) 그 조건을
결론에서 떼어내고 장치의 항구적 성질로 승격시켰다.

증거를 더 세게 확인할수록(전수 3,105건) 결론이 더 단단해 **보이는** 것이 함정이었다.
표본 수는 **같은 조건 안에서만** 신뢰도를 올린다 — 조건 밖으로는 한 발짝도 옮겨주지 않는다.

부수적으로, 이 잘못된 전제 위에 **코드를 더 정교하게 쌓았다.** 리팩터 중 `homing` 인터록과
판독 동결을 `_pos_frozen` 으로 분리하며 "복귀 이동이 화면에 그려지도록 개선했다" 고 보고했다.
전제가 틀렸으므로 그 정교화는 결함을 더 정밀하게 구현한 것이었다.

## 재발 방지

- **구현 수정** — 통째 동결을 없애고 `decode_frames` 가 **정확히 0 인 표본만** 버린다.
  리밋에 실제로 있을 때의 판독도 596·543 처럼 0 이 아니므로 정확한 0 은 sentinel 로 본다.
  호밍 중 각도가 실시간으로 갱신되고 바퀴 그림이 스윙을 따라간다.
- **회귀로 강제** — `test_homing.py` 3건 신설(106 → 107): 0 표본은 버린다 / **`homing=True`
  인 동안에도 실측이 반영된다** / 간헐 0 이 직전 실측을 덮어쓰지 않는다.
  두 번째가 이 사건의 직접 회귀다 — 동결 가드가 되살아나면 깨진다.
- **관측 인용 규칙** — 실기 관측을 근거로 쓸 때 **측정 조건을 결론에 붙여서** 적는다
  ("Seer 폴링에 대한 응답" vs "우리 폴링에 대한 응답"). 조건이 다른 경로에 적용하려면
  그 경로에서 **다시 측정**한다. 표본 수는 조건 밖으로 결론을 옮겨주지 않는다.
- **남은 불확실을 등록** — 간헐 0 의 발생원(드라이브 재기준 vs 두 마스터 폴링 경합)과
  대각도 스윙 중 매끄러운 추종은 미확증이다. `debt-017` 로 등록했다. 이번 run 은 조향이
  이미 홈 근처였으므로 **"지속 0 아님" 만 확증**이고 그 이상은 주장하지 않는다.
