# 2026-08-24 17:00 (KST) — PGV 용도를 묻지 않고 라인 추종으로 추정해 ADR 에 적었다

## 무엇을 했는가

사용자가 "PGV 구현 패키지 설치"만 요청하고 **용도를 말하지 않았는데**, 저장소 정황
(현재 브랜치명 `linefollow-*`, `trnav_2ws_action_server` line_follow, `src/AI/line_vision`)
에서 용도를 추정해 ADR Context 에 "PGV 의 Y 편차·각도 출력은 그 계열(라인 트래킹 주행
스택)의 센서 입력 후보다"라고 적었고, 미검증 부채(debt-125)의 ③컬러 상대각·④색 선택도
언젠가 필요한 검증 항목처럼 등재했다.

## 무엇이 잘못이었나

실제 용도는 **도킹 정밀도 검증용 독립 계측 기준**이었다(2026-08-24 사용자 확언).
계측 용도에는 Data Matrix 태그만 쓰므로 컬러 테이프 전용 기능(③④)은 해당이 없고,
mux/모션 체인 통합도 불요하다. 추정 용도가 ADR 이라는 결정 기록에 실려, 후속 세션이
"PGV → 라인 추종 입력"을 기정사실로 읽을 수 있는 상태였다.

## 사용자 지적

> "PGV는 도킹 정밀도 검증용입니다." → (색 선택 논의에) "도트 매트릭스는 흑백인데.." →
> "레인 추종은 한다고 안했는데"

두 차례에 걸쳐 교정됐다 — 첫 확언 후에도 내가 ③④를 "남은 검증"으로 계속 세는 바람에
두 번째 지적이 필요했다.

## 원인 분석

`intent-guess` — 요청문에 용도가 없을 때 "무엇에 쓰실 겁니까" 1줄을 묻는 대신,
저장소 정황(브랜치명·기존 스택)을 근거로 삼아 추정을 채웠다. 추정을 "후보다"로
헤지하긴 했으나, ADR·부채 등재라는 **오래 남는 자산**에 실었기 때문에 헤지가
무력했다 — 문서에 남은 추정은 후속 독자에게 사실처럼 작동한다.

## 재발 방지

- 장치·센서류 신설 ADR 의 Context 에는 **사용자가 말한 용도만** 적는다. 용도 미상이면
  "용도 미확인 — 사용자 확인 대기"로 적지, 정황 추정으로 채우지 않는다.
- 반영: [docs/adr/2026-08-24-pgv-driver.md](../adr/2026-08-24-pgv-driver.md) Context 의
  라인 추종 추정 문장을 실제 용도(도킹 정밀도 검증)로 정정, debt-125 에 ③④ 비적용
  조건 부기(차기 커밋 반영). 메모리
  `biguamr-pgv-docking-metrology`(용도 정본)는 첫 확언 직후 이미 기록.
