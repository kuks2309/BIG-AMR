# 2026-08-06 18:40 (KST) — coding SOP §2 사전조사(함수표·전역변수표) 미이행 상태로 패키지 신설·수정

## 무엇을 했는가

2026-07-28 에 `src/AI/yolo_detector` 패키지(`detector_node.py`·`detection.py`)를 신설하고,
이후 여러 차례 수정했다. 그 사이 **함수표·전역변수표를 만든 적도 읽은 적도 없다.**
표 없이 세운 구조가 「라운드로빈 단일 추론」이며, 그 설계 근거로 두 파일 docstring 에
*"GPU 는 한 번에 한 프레임만 처리하므로 6대를 동시에 돌릴 수 없다"*
(`detection.py:8-9`, `detector_node.py:10-11`)를 검증 없이 단정해 적었다.

2026-08-06 성능 조사에서 그 전제가 반증됐다 — 배치 6장이 프레임당 CPU 를
**18.83 → 5.68 ms**, 처리량을 **48.95 → 90.03 fps** 로 바꾼다(같은 조건 연속 측정).
즉 표를 갖추지 않은 채 세운 구조가 수신 프레임의 약 83%를 버리고 있었다.

## 무엇이 잘못이었나

- `docs/claude_guideline/coding/coding.md` §2 사전조사 `:41` —
  *"코딩 계획 전에, 함수표·전역변수표를 먼저 갖춰 읽는다."*
- 같은 §2 `:43-46` — *"표가 없으면 먼저 만든다 … 신규 파일(처음 작성) → coding 의 계획
  단계에서 표를 생성한다"*. 본 패키지는 신규 작성이었으므로 계획 단계 생성 대상이었다.
- 같은 §2 체크박스 `:59-61` — 표를 읽었다 / 그 표로 중복 함수·변수를 확인했다.
  세 항목 모두 이행하지 않았다.

## 사용자 지적

> "코드 규칙에 다라서 함수 테이블, 변수 테이블을 만들고 그것을 참조해서 코딩을 하나요?"
> → (미이행 답변 후) "안헀으면 규칙 위반인데"

직전 지적도 같은 뿌리였다 — "지금 구조를 잘 이해 못하고 이상하게 만들었네".
구조가 이상해진 원인이 §2 미이행이라는 점을 사용자가 순서대로 짚었다.

## 원인 분석

가시성은 충분했다. `coding-reminder.py`(UserPromptSubmit)와
`coding-inventory-gate.py`(PreToolUse)가 **둘 다 `.claude/settings.json` 에 실제 등록돼
있다**(각각 8행, 170·232행). 규칙도 루트 `CLAUDE.md` 의 「코드 작성 SOP」 절에 등록돼 있었다.

그런데도 막히지 않은 이유는 **게이트의 기본값**이다. `coding.md:53` 이
*"표가 아예 없으면 통과가 기본값이다(인벤토리 미도입 프로젝트를 전면 차단하면 훅이 꺼져
강제력이 0 으로 회귀한다)"* 라고 정의한다. 즉 **표를 만들지 않는 위반이 곧 그 위반을 잡을
게이트를 무력화**한다 — 표를 한 번도 만들지 않으면 영원히 통과한다. 자기참조 구멍이다.

`CODING_GATE=strict` 로 그 기본값을 뒤집을 수 있으나 이 저장소에는 설정돼 있지 않다.
루트 `CLAUDE.md` 상단의 「강제 장치 미설치 고지」가 서술하는 상태(pre-commit·CI 부재)와도
겹쳐, `⟦CI:*⟧` 계열은 애초에 강제되지 않는다.

## 재발 방지

**표를 신설해 게이트의 기본-통과 조건을 제거했다.** 이제 이 모듈에 표가 존재하므로,
`coding-inventory-gate.py` 는 `detector_node.py`·`detection.py` 수정 시 **그 표를 이번
세션에 읽었는지 검사하고 미독이면 도구 호출을 거부**한다(coding.md:51-52). 즉 본 entry 의
재발 방지는 문서가 아니라 **이미 등록된 훅이 실제로 작동하게 만든 상태 변경**이다.

- 신설: `docs/code_review/ai-yolo-detector/2026-08-06.md` (루트 정본)
- 병기: `src/AI/yolo_detector/docs/code_review/ai-yolo-detector/2026-08-06.md` (모듈 로컬 권위)
- 내용: 함수표 18행 · 전역변수표 8행 · 인스턴스 상태표 13행 · ROS 인터페이스표 5행 ·
  구조 관찰 6건. 위치 컬럼은 게이트가 요구하는 `파일명:줄` 앵커 형식(총 55개).

남은 구멍은 **다른 미도입 모듈**이다. 같은 자기참조 구멍이 표 없는 모든 패키지에 그대로
있으며, 저장소 전역으로 닫으려면 `CODING_GATE=strict` 설정이 필요하다. 이는 모든 세션의
작업을 차단하는 변경이라 사용자 승인 사항으로 남긴다 — `docs/debt/registry.md` 에
등록해 추적한다.
