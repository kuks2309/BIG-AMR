# 2026-07-28 21:07 (KST) — 화면 한 번 안 보고 UI 결함을 네 번 오진

## 무엇을 했는가

"조향 슬라이더를 움직여도 바퀴가 조향이 안 된다"는 보고에 대해, **실행 중인 창을 한 번도
캡처하지 않은 채** 원인 가설을 세 차례 세우고 그중 둘을 수정으로 밀어붙였다:

1. `_sync_sliders` 되먹임이 눈금을 되돌린다 → 제거(실제 결함은 맞았으나 원인은 아니었다)
2. Seer 는 `0x607A`+`0x6040` 을 48 Hz 로 재송신하는데 우리는 1 회뿐이다 → 재송신 필요 주장
3. `0x6060`(모드)·`0x6040=0x86`(축 준비)을 우리가 안 보낸다 → 브링업 필요 주장

사용자가 "안됨"·"앞뒤바퀴 조정이 역시 안됨"·"안됨"·"안된다고" 를 **네 번** 말한 뒤에야
화면을 캡처했다. 실제 원인은 첫 캡처에서 즉시 보였다 — **슬라이더가 78×20 px** 이라
(범위 ±90° = 181 단계, 1 px = 2.3°) 핸들을 잡을 수 없었다.
