# 2026-08-25 19:38 (KST) — crab 을 "실기 미검증 위험 기동"으로 단정 — 기록 검색 없이

## 무엇을 했는가

PGV(Position Guided Vehicle) 축 판별을 위한 좌우 10 mm 이동 제안에 대해
"crab(조향 ±90°)은 실기 미검증 기동이라 위험합니다"라고 답하며 로봇 이동 대신
매트 슬라이드를 제안했다. 근거는 08-08 자 런북의 "crab_linear — 별도 계획 필요" 문구뿐.

## 무엇이 잘못이었나

crab 은 이미 실기 검증돼 있었다 — `docs/adr/2026-08-15-line-follow-common-diff-control.md:60`
("crab_linear 로 실기 검증된 코드다") · `docs/issues_and_fixes/issues_and_fixes.md:1293`
(실기 Phase 0 통과) · 7월 amr_test_gui crab 조그 IMU 실증. `grep -rn crab code_updates/ docs/`
한 번이면 수 초 만에 나오는 기록을 찾지 않고, 17일 묵은 런북 문구로 "미검증"을 단정해
사용자의 실험 설계를 잘못된 안전 사유로 반려했다.

## 사용자 지적

> "이미 실험 다했는데 제발 기록 검토를 왜 안할까?"

## 원인 분석

category: context-missing — 「보유 원자료를 조사 후보에 넣지 않는다」 메타 패턴의 6번째 사례
(2026-08-03-002 · 08-05-001 · 08-06-004 · 08-07-002 · 08-24-002 와 동일 공백).
이번 변형: **"위험하다"는 안전 판단으로 포장된 부재 단정** — 안전 사유는 보수적일수록
좋다는 편향 때문에 "미검증" 주장에 대한 검증 의무를 스스로 면제했다. 직전 사례(08-24-002)의
교훈("검토 착수 전 식별자 전수 grep 1회")이 세션 시작 주입에 있었는데도, "주행 계획"이라는
다른 작업 맥락이라 검색 트리거로 연결하지 못했다.

## 재발 방지

- INDEX §메타 패턴에 본 사례 추가: 교훈을 「검토 대상」에서 **「'없다/미검증/위험' 단정 전부」**로
  확장 — 능력·검증 이력·자산의 부재를 주장하는 문장을 쓰기 전에 그 식별자로 저장소 전수
  grep 1회는 의무. 안전 사유(보수적 판단)도 면제 대상이 아니다 — 잘못된 안전 주장은
  올바른 실험을 막는 실비용이 있다.
