# ADR 2026-07-28 — 구 amr_test_gui 패키지 폐기, 단일 파일 `gui.py` 로 대체

- 작성: 2026-07-28 (KST) · sess 56a709a5
- 상태: **채택** (사용자 지시 — "기존 이상한 gui삭제 부탁", 2026-07-28 15:2x)
- 대체 대상: [2026-07-27-amr-test-gui.md](2026-07-27-amr-test-gui.md) (해당 ADR 의 **구현 결정만** 폐기, 안전 원칙은 유지)

## 배경

2026-07-27 에 `Tools/amr_test_gui/amr_test_gui/` 11 모듈 + 테스트 6 파일(84건)로
구 GUI 를 만들었다. 사용자 평가는 **"gui는 사용자 편의성, 디자인 등을 고려해야 하는데 지금은
너무 엉망임"**(2026-07-27) 이었고, 이후 사용자가 레이아웃을 한 단계씩 지시하며
`Tools/amr_test_gui/gui.py` 단일 파일로 **처음부터 다시** 만들었다.

신 GUI 가 실기에서 동작 확인된 시점(2026-07-28 15:20, 사용자 확인 "잘 움직이네요")에
두 구현이 나란히 남아 있을 이유가 없어졌다.

## 결정

1. **삭제** — `amr_test_gui/`(패키지 11 파일) · `run_gui.py` · `test/`(6 파일).
2. **유지** — `gui.py`(단일 파일, 자립형). 구 패키지를 import 하지 않음을 삭제 전 확인했다
   (`grep '^import\|^from' gui.py` → 표준 라이브러리 + PyQt5 뿐).
3. **이력 보존** — 구 GUI 는 커밋 `fdc1c51`(브랜치 `session/56a709a5`)에 **`Tool/amr_test_gui/`**
   (단수 `Tool`) 경로로 21 파일이 남아 있다. 이후 저장소 배치 규약에 따라 워킹트리가
   `Tools/`(복수)로 옮겨지면서 추적에서 빠진 상태였다. 복구가 필요하면 그 커밋을 볼 것.

## 폐기되는 안전 자산과 그 대체

| 폐기 자산 | 무엇을 강제했나 | 대체 |
| --- | --- | --- |
| `ramp.py` | ±90° 하드 클램프 + ≤30° 단계 램프 + 미추종 시 FAULT 래치 | **±90° 클램프만** `gui.py` `_steer_to`·`_steer_axis` 로 이관. **단계 램프·FAULT 래치는 대체 없이 폐기** |
| `test/test_ramp.py` (16건) | 급점프·범위이탈·FAULT 래치 회귀 | 없음 — `gui.py` 회귀 테스트 신설 필요 |
| `panda_can_bus.py` | 정본 backend ↔ 판다 어댑터 | `gui.py` 가 `_sdo_write` 로 판다에 직접 송신(정본 backend 미경유) |
| `modes.py` | 8방향 모드 인용 테이블(부호 정합) | `gui.py` 의 `JOG` 딕셔너리 |
| `sim_bus.py` | dry-run | 없음 — **실기 전용**이 사용자 결정(2026-07-28) |

### ⚠ 단계 램프를 대체 없이 폐기한 근거

단계 램프는 **시스템의 방식이 아니었다.** 사용자 판정: "램프는 이 시스템의 방식이 아닙니다.
제가 만들어낸 메커니즘입니다. 엉터리 가정은 생략하고 가동범위 제약함 하면되지"(2026-07-28).
실기 캡처가 이를 뒷받침한다 — `Log/homing_capture_220350.jsonl` 에서 Seer 는 `0x607A` 를
node3 기준 6,464 회 송신하지만 **서로 다른 값은 4 개뿐**이고, 이동 프로파일은 드라이브가 수행한다.
경위는 [claude-mistake 2026-07-28-003](../claude-mistake/2026-07-28-003_invented-steer-ramp-mechanism.md).

⇒ 단계 램프가 필요한 시험이 있다면 그것은 **사용자가 지정한 시험 절차**이지 시스템 요구가 아니다.
   두 가지를 구분해 인용할 것.

## 남는 부채

- **FAULT 래치 부재** — 조향이 목표를 추종하지 못해도 `gui.py` 는 정착 대기 timeout 후 구동을
  취소할 뿐(`_wait_settle` → `_jog_run`), 이후 지령을 봉쇄하는 래치가 없다. 등록: **debt-010**.
- **`gui.py` 테스트 0건** — 구 테스트 84건이 함께 삭제됐다. 등록: **debt-011**.
- debt-005 는 대상 파일(`panda_can_bus.py`) 소멸로 **무효화**한다. debt-006 의 Node Guarding
  질문은 `gui.py` 의 `_sdo_write` 경로에도 그대로 적용되므로 **재등록**한다(**debt-012**).

  (debt-008·debt-009 는 다른 세션이 선점한 id 라 사용하지 않았다.)

## 검증

- 실행 중이던 GUI(pid 411588)는 영향 없음 — 자립형.
- 삭제된 경로를 인용하던 문서 18 파일 34 곳을 정정(본 ADR 을 앵커로).
