# ADR 2026-08-23 — 2WS 도킹 W3: 액션 서버·지령 체인 결합

- **Status**: Accepted — 2026-08-23 (사용자: "커밋 푸쉬 후 계속 진행" — W2 완료 연속 승인.
  실기 구동 전 게인·부호는 실기 검증 필수)

## Context

- W1(코어 무수정 이식)·W2(2WS IK steer-hold + `/wall_pose` 관측 어댑터) 완료 — ctest 11/11.
- 지령 체인 사전조사(실측): mux 에 **도킹 채널이 이미 예약**돼 있다 —
  `trnav_motion_mux.yaml:158` `source_40 "dock"`, topic `/motion/wheel_cmd/dock`,
  timeout 200 ms. 소스 전환은 `trnav_msgs/srv/SelectMotionSource`
  (`trnav_motion_mux_node.cpp:52-56`). 액션 서버들의 지령 메시지는
  `trnav_msgs/msg/WheelSetArray`(전/후 속도·조향 — 코어 `DockWheelCommand` 와 동형).

## Decision

**신규 패키지 `src/Control/Motion_Control/2WS/trnav_2ws_dock_ros/`** (ament):

1. **액션 인터페이스** — 2WS 관례대로 `trnav_2ws_interfaces` 에
   `AMRMotionDockApproach.action` 추가(공개표면):
   goal = 목표 자세(스테이션 프레임)·접근축(base_link 기준 deg)·허용오차(d/lat/yaw)·
   timeout, feedback = phase·3축 오차, result = success·stop_reason·최종 오차.
2. **노드 구성** — `/wall_pose`(+진단) 구독, 제어 주기 타이머(기본 30 Hz):
   `wallPoseToDockObs` → 페이즈 로직 → 코어 함수(distPidStep·geomEntryDeltaBiased·
   phase4Steer·composePhase4Wheels·phase4Vcap) → `WheelSetArray` 를
   `/motion/wheel_cmd/dock` 발행. 액션 수락 시 `SelectMotionSource(40)`, 종료·중단·취소
   시 정지 지령 + 이전 소스 복원.
3. **페이즈 최소안**(orbit 생략 — yaw 는 `/wall_pose` 상시 관측 + 속도차 yaw 미세 보정):
   `PRE_ALIGN`(geomEntryTranslateNeed > 0 일 때만 — 도크면 평행 translate 로 수평 소거)
   → `APPROACH`(거리 PID + 기하 진입 crab + 근접 감속 phase4Vcap — ANT adjusted stop 대응)
   → `VERIFY`(정지 후 N 사이클 평균으로 허용오차 판정, 미달 시 재접근 1회) → 완료.
4. **안전 게이트** — 관측 신선도(기본 0.2 s)·LOST 유예(steer-hold 정지 — 원본
   returnHomeAbort 의 대기 규약 재사용)·yaw runaway 상한(초기엔 `/wall_pose` yaw 로,
   IMU 결선은 후속)·전체 timeout. 어떤 종료 경로든 **정지 지령 → mux 원복** 순서.
5. **검증** — 단위(페이즈 전이·게이트) + **폐루프 SIL**: 시뮬레이터가
   `/motion/wheel_cmd/dock` 을 소비해 기구학 적분으로 로봇을 움직이고 가상 벽 스캔을
   재생성(기존 wall_localizer sim 킷 확장) → wall_localizer → dock 노드 전 체인.
   HIL 은 게인·부호 실기 검증과 함께(사용자 입회).

## 방향·검증 확정 (2026-08-24 사용자 답변)

- **도킹 대상 = 접촉 없는 목표 위치 정밀 도달** (카메라 미사용, 벽 3면 `/wall_pose` 단독).
  접촉면 제약이 없으므로 **접근 방향 = 전방(approach_axis 0°)** 확정 — 폐루프 SIL 로
  검증 완료된 경로. 측면·후방은 goal 파라미터로 열려 있으나 기본 운용은 전방.
- **정밀도 실측 = PGV(Position Guided Vehicle 센서, 바닥 데이터매트릭스 태그 판독)** —
  벽 측위와 독립인 참값 소스로 도달 정확도·반복성을 검증한다. 저장소에 PGV 드라이버는
  아직 없음(2026-08-24 전수 검색) — HIL 1차는 수동 판독, 통합은 필요 시 후속.

## Consequences

- 이득: 기존 mux 채널·서비스·메시지 재사용으로 하단 배선 신설 0. 코어·어댑터는
  검증 완료 상태라 W3 는 조립·페이즈만 신규.
- 비용: 공개표면 1(액션) 추가, trnav_2ws_interfaces 수정.
- 남는 위험: ① 게인(원본 px 단위)·arm_m 의 m 단위 재환산은 SIL 로 초기값을 잡고
  실기 튜닝 ② 접근축·조향 부호는 실기 검증 전 미확정(설정 주입) ③ source_40 의
  기존 예약 주석(amr_dock_align, 2026-06-02)과 발행자 충돌 여부는 기동 게이트에서 확인.

## Rollback

N/A (가역) — 신규 패키지 + 인터페이스 1파일 추가. mux 설정은 무변경(기존 예약 사용).
