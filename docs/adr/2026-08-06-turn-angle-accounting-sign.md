## Context

`turn` 은 목표까지의 진행량 `accumulated_angle` 을 IMU(Inertial Measurement Unit) yaw
**델타 누적**으로 잰다. 계상 지점이 세 곳인데 **주 루프만 방향을 보지 않았다**:

```
주 루프      accumulated_angle += std::abs(delta_yaw) * 180.0 / M_PI;   ← 방향 무시
정착 블록    if (sign * delta_deg > 0) += |d|; else { -= |d|; clamp0; }
미세보정     동일
```

`std::abs` 는 **뒤로 읽힌 델타까지 전진으로 계상**한다. 잡음이 좌우 대칭이어도 항상 더하므로
편향이 한 방향으로만 쌓이고, 결과적으로 **덜 돌았는데 다 돌았다고 판정**한다.

**왜 지금까지 드러나지 않았나** — SIL 플랜트가 지령을 되울리고 잡음이 없어 델타 부호가
뒤집히지 않았다. 그 조건에서는 `std::abs` 와 부호 반영이 **완전히 같은 값**을 낸다
(측정오차 0.000°). 2026-08-06 에 플랜트에 관성·조향 슬루·IMU yaw 잡음을 넣고서야 드러났다
(`docs/adr/2026-08-06-turn-spin-removal-and-sim-plant-dynamics.md` D2·D3).

**측정** — 목표 45° · R=1.0 m · 관성 0.6 s · 조향 슬루 57.1 deg/s. 액션의 자기보고와
IMU 지상진값을 분리해 비교(`Tools/motion_chain_check/turn_residual_probe.py`):

| 조건 | 액션 보고오차 | **실제오차** | 측정오차 | σ(실제) |
| --- | --- | --- | --- | --- |
| 즉응·무잡음 | +0.172° | +0.172° | 0.000° | 0.000 |
| 동특성·무잡음 | +0.294° | −0.019° | +0.312° | 0.000 |
| **동특성·잡음 0.05°** | +0.245° | **−0.536°** | **+0.780°** | 0.221 |

액션은 **언제나 「임계 안」이라고 본다**(+0.19~+0.30° < `fine_correction_threshold_deg` 0.3°).
그런데 실제로는 0.34~0.85° 덜 돈다. **자기 측정오차가 보정 임계보다 커서** 미세보정이
이 부족분을 볼 수 없다.

**돌연변이 대조** — 주 루프만 부호 반영으로 바꾸고 동일 조건 재측정:

| | 종전 `std::abs` | 부호 반영 |
| --- | --- | --- |
| 실제오차 평균 | −0.536° | **−0.211°** |
| 실제오차 \|최대\| | **0.846°** | **0.298°** |
| 실제오차 σ | 0.221° | **0.065°** |
| 임계 0.3° | **달성 불가** | 달성 |

## Decision

**D1.** 주 루프의 계상을 `accumulated_angle += sign * delta_deg` 로 바꾸고 0 하한을 둔다.

이 식은 정착·미세보정 블록의 `if/else` 와 **수학적으로 동일**하다 —
`sign·d > 0` 이면 `|d| = sign·d` 이므로 `+= |d|` 와 같고, `sign·d < 0` 이면 `|d| = −sign·d`
이므로 `−= |d|` 와 같다. 즉 새 규칙이 아니라 **주 루프만 빠져 있던 같은 규약**을 맞춘 것이다.

**D2.** QD 상류(`QD/…/turn_action_server.cpp:233`)는 **건드리지 않는다.** 같은 결함을 갖지만
별도 스택이고 본 기체(Foil_A082, 2WS)가 쓰지 않는다. 이 저장소의 2WS 만 정정한다.
이로써 「2WS = 검증된 QD + 승인된 이탈」의 승인 이탈이 **세 건**이 된다.

> 여기서 고친 「델타 누적의 부호 처리」는 **누적 자체가 절대 목표 yaw 방식으로 대체되어 사라졌다.**
> D3 이 지목하는 `turn_angle_accounting_check.py` 도 **2026-08-10 폐기**했다(검사 대상 소멸 +
> 무관한 `std::fabs` 를 잡는 오탐). 아래 서술은 이력으로 보존한다.

**D3.** 회귀는 `Tools/motion_chain_check/turn_angle_accounting_check.py` 로 소스에서 재도출해
고정한다. 세 지점 중 하나라도 방향을 무시하면 `exit 1`.

## Alternatives (기각)

- **`spin` 방식으로 전환** — `spin` 은 시작 시 **절대 목표 yaw** 를 잡고
  `normalizeAngle(target_imu_yaw − cur_yaw)` 로 잰다(`spin_action_server.cpp:276`). 델타 누적
  자체가 없어 편향이 **원천 소거**되므로 원리적으로 더 낫다. 다만 Phase 완료 판정·피드백·
  정착 로직이 전부 `accumulated_angle` 에 묶여 있어 구조 변경이 된다. **별건으로 남긴다.**
- **미세보정 임계를 올린다** — 증상만 가린다. 부족 회전 자체가 사라지지 않는다.
- **현행 유지(QD 정합 우선)** — 사용자 판단으로 기각(「채택 안 하면 안 되는 것이네」).

## Consequences

**이득** — 잡음 조건에서 실제 회전 오차 최대 **0.846° → 0.298°**(2.8배), σ 3.4배 개선.
미세보정 임계 0.3° 가 처음으로 달성 가능해진다.

**비용** — QD 상류와 한 줄 더 갈라진다(승인 이탈 3건째). 상류 변경 병합 시 수동 확인 필요.

**무영향 확인** — 즉응·무잡음 조건에서 결과가 **변경 전과 완전히 동일**하다
(45.172° · 7.40 s · σ 0.000, 3회). 델타 부호가 뒤집히지 않는 조건에서는 두 식이 같은 값을
내므로 기존 2WS SIL 결과는 바뀌지 않는다.

**남는 위험·부채**
- 잡음 **0.05° 1σ 는 가정값**이다. `References/` 에 iAHRS 자료가 없어 실기 잡음 크기를
  모른다. 기전과 방향(항상 부족 회전)은 확정, **실기에서의 크기는 미확정**.
- 임계 0.3° 여유가 **0.002° 뿐**이라 실기 잡음이 조금만 커도 초과한다. 근본 해소는 위
  Alternatives 의 `spin` 방식 전환.
- 측정오차 자체는 +0.397° 가 남는다(데드밴드 이월·관성 구간 계상 등 다른 요인).
- 실기 검증 0회.
