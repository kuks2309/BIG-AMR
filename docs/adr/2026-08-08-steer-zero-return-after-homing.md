## Context

「호밍하면 조향이 0° 로 돌아온다」는 서술이 자산 여러 곳에 있으나, **어느 경로도 0° 를 지령하지 않는다.**

### ① 펌웨어 시퀀서 경로 (`0xea`/`0xeb`) — 0° 가 아닌 지점으로 간다

`Tools/Can_Relay/panda-firmware/board/safety/safety_seer_gate.h` 의 호밍 상태기는
`WAIT` → `RESTORE`(:474-482) → `GOZERO`(:484-491) → `GOZERO_W`(:493-526) → `DONE` 으로,
`GOZERO` 에서 `0x607A` 에 아래 상수를 쓴다(:212-213):

```c
#define SEER_HOME_ZERO_N3   7882020
#define SEER_HOME_ZERO_N4   7859062
```

이 값은 **호밍 후 정착값**(Seer 마스터가 `0x607A` 로 지령하던 값을 캡처해 옮긴 것)이며
**조향 0° 가 아니다.** 실측 0° 는 `[7871815, 7840086]` 이고 차이는
**+10,205 / +18,976 counts = +0.178° / +0.331°** 다.

- 실측 근거: 호밍 10회 연속에서 정착값 node3 `7,882,021` · node4 `7,859,065` 재현(σ ≈ 3 counts).
  산출 `Log/home_experiment_260803_153319.jsonl` · `_summary.json`.
- 도달 판정 허용오차 `SEER_HOME_ZERO_TOL = 57344` 은 **정확히 1.0°** 라 이 편차보다 3~5배 크다
  ⇒ **펌웨어는 「0° 가 아니다」를 원리적으로 검출하지 못한다.**
- 2026-08-03 커밋 `1acc354` 가 `Tools/docking_field_kit/orin_homing_run.py` 의
  「0° 복귀」 라벨을 **오라벨로 판정해 정정**했다(현행 주석: "GOZERO 지점으로 복귀한다(조향 0° 아님)").
- 상수 자체의 문제(이름이 사실과 어긋남 · 허용오차가 오인을 못 막음)는 **debt-034 미해결**,
  같은 편차를 「영구 미검출 오프셋」으로 등록한 **debt-016** 도 별건으로 열려 있다.

### ② `Tools/amr_test_gui/gui.py` 경로 — 0° 복귀 지령을 한 번도 내지 않는다

`_homing_run`(:1180-1201)은 호스트가 직접 `0x6040=0x86` → `0x6099` → `0x60FB:04=1` 을 쓰고
`_wait_homed()`(:1203-1229)로 `0x6041` bit15 만 본다. 성공 메시지는
`"…초 소요. 조향 0° 복귀까지 확인하세요."` — **지령이 아니라 육안 확인 요청**이다.
이 경로에는 `GOZERO` 에 해당하는 단계 자체가 없다.

### 왜 펌웨어 상수 교체가 아닌가

`SEER_HOME_ZERO_N3/N4` 를 실측 0° 로 바꾸면 해결되지만 **펌웨어 재빌드·플래시**가 따르고,
debt-034 상환계획 ①이 그 작업을 「다른 펌웨어 변경과 묶어 1회로 처리」하도록 이미 정해 두었다.
0° 복귀는 **`0x607A` + `0x6040=0x3F` 지령 한 벌**이면 되고, 두 경로 모두 그 지령 원시함수를
이미 갖고 있다(`RelayBackend.set_steer_deg` · `gui.py:_steer_to`). 펌웨어를 건드릴 이유가 없다.

## Decision

**호밍 완료 후, 호스트가 조향 0° 복귀 지령을 한 번 더 낸다.** 펌웨어 상수는 건드리지 않는다.

1. **0° 의 정본은 하나다** — `src/Comm/CAN/can_relay/config/machine/foil_a082.yaml`
   `steer_home_counts: [7871815, 7840086]`. 새 상수를 만들지 않는다.
   두 경로 모두 기존 환산 함수를 그대로 쓰므로 「0° 지령」 = `steer_home_counts` 그 자체다
   (`safety.steer_deg_to_counts(n, 0.0, …) == steer_home[n]`, `gui.steer_counts(n, 0.0) == STEER_HOME[n]`
    — 각각 `test_steer_origin.py:47` · `test_gui_math.py:34` 가 고정).

2. **can_relay** — `RelayBackend.home()` 를 래퍼로 바꾸고, 호밍 시퀀스가 성공하면
   새 공개 메서드 `steer_to_zero()` 를 이어서 호출한다.
   - `steer_to_zero()` 는 `set_steer_deg(0.0)` 로 목표를 세우고 `settled()` 로 도달을 확인한다.
     기존 안전 게이트(E-stop · 호밍 중 거부 · `homed_effective()` · ±limit 클램프)를 **그대로 통과**한다 —
     우회 경로를 새로 만들지 않는다.
   - 호밍 성공 + 0° 복귀 실패는 **`home()` 전체를 실패로 보고**한다. 「호밍은 됐는데 어디 서 있는지 모른다」를
     성공으로 적으면 그 다음 구동이 열린다.
   - 파라미터 `steer_zero_after_home`(기본 `true`) · `steer_zero_timeout_s`(기본 `10.0`) 로 끌 수 있다.
     끄면 종전 동작(정착값에 정지)이다.

3. **gui.py** — `_homing_run` 에서 `_wait_homed()` 성공 직후 `_steer_to(0.0)` 를 내고
   `_wait_settle(0.0, tol)` 로 도달을 확인한다. 실패하면 로그를 「미확인」으로 적는다.
   성공 메시지의 "조향 0° 복귀까지 확인하세요"(육안 위임)를 실제 지령·확인으로 대체한다.

4. **이동량 상한은 기존 클램프가 보증한다** — 0° 지령도 `±steer_limit_deg`(90°) 클램프를 지나므로
   이 변경이 새로운 대각도 스윙을 만들지 않는다. 펌웨어 경로에서 예상 이동량은
   0.178°/0.331°(정착값→0°)이나, **그 값은 계산이고 이 변경의 실기 확인은 아직 없다.**

## Alternatives (기각)

- **펌웨어 `SEER_HOME_ZERO_N3/N4` 를 실측 0° 로 교체** — 재빌드·플래시 동반. debt-034 ①이
  다른 펌웨어 변경과 묶기로 이미 정해 둠. 기각(연기).
- **`SEER_HOME_ZERO_TOL` 을 조여 편차를 검출** — 도달 판정이 조여지면 정상 호밍이 실패로 뒤집힌다.
  debt-034 ②가 「도달 판정 1.0° 유지, 0° 대조는 별도 진단으로 분리」로 이미 방향을 정함. 기각.
- **호밍 완료 판정에 위치 조건을 추가** — 0° 로 **보내는** 문제이지 **판정**하는 문제가 아니다. 기각.

## Consequences

**이득**
- 호밍 후 조향이 실제로 0°(정본 `steer_home_counts`)에 선다 — 두 경로 모두.
- 「0° 복귀」라는 기존 서술이 처음으로 사실이 된다. 라벨과 동작의 불일치가 닫힌다.
- 펌웨어 재플래시 없이 닫힌다 — 현장 판다를 건드리지 않는다.

**비용 / 남는 위험**
- 호밍 소요시간이 0° 정착 대기만큼 늘어난다(상한 `steer_zero_timeout_s`, 기본 10초).
- **실기 미검증** — 단위/회귀만 통과했다. 특히 gui.py 경로는 `GOZERO` 가 없어 호밍 직후 축이
  어디에 서는지 이 세션이 실측하지 않았다. 이동량이 예상(≤0.34°)보다 클 수 있으므로
  **첫 실기는 이동구역 확보 또는 잭업 상태**에서 할 것.
- **debt-034 · debt-016 은 닫히지 않는다.** 상수 이름이 사실과 어긋나는 문제와
  허용오차가 오인을 막지 못하는 문제는 그대로다 — 이 ADR 은 「0° 로 보내는 것」만 해결한다.
- `Tools/amr_test_gui/amr_test_gui/`(리팩터 진행분)의 상태 라벨은 여전히 펌웨어 GOZERO 를
  「0° 지령」·「0° 복귀 중」·「완료 (조향 0°)」로 적고 있다(`panda_can_bus.py:135-139`).
  이번 범위 밖 — 별도 정정 대상.

## Rollback

가역. 되돌리는 절차:

1. **can_relay** — 파라미터만으로 즉시 무력화: `steer_zero_after_home: false`
   (`config/machine/foil_a082.yaml` 또는 런치 인자). 코드 원복은
   `RelayBackend.home()` 래퍼를 종전 단일 메서드로 되돌리고 `steer_to_zero()` 를 삭제.
2. **gui.py** — `_homing_run` 의 0° 복귀 블록 삭제. 다른 상태를 남기지 않는다
   (`_steer_to` 는 기존 함수이고 새 전역·영속 상태를 만들지 않았다).
3. 펌웨어·설정 상수는 **변경하지 않았으므로 원복 대상이 없다**. 플래시 불필요.
