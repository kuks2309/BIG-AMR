# ADR 2026-08-10 — `yaw_control` 조향 미도달 지속 감시 (status −8)

- **Status**: Proposed — 2026-08-10 (**검증 전**. 최종 verdict 는 저자가 찍지 않는다 —
  `coding.md:88` never-self-approve)
- **Rollback**: 가역 — `git revert`. 영속 상태·스키마·펌웨어 변경 없음.
  `.action` 에 status 코드 하나가 추가되나 기존 0/−1~−7 의 의미는 불변이다.

## Context

2026-08-10 실기에서 조향축이 비응답 상태였을 때(`debt-051`) `yaw_control` 이 **60초를
아무 진단 없이 대기**했다.

```
액션 발행 −20.21° → mux 통과 → /motor/low_cmd node3 target_pos = 지령각 일치
실제 조향 −0.00°                     ← 모터가 안 움직임
결과      status −3(전역 타임아웃) · 거리 0.001 m · 60.0 s
```

`TransientGuard` 는 조향 오차가 `steer_gate_threshold`(3°)를 넘으면 `gate_blocked` 로
**구동 속도를 0 으로 묶는다**(`:441-442`). 안전 동작으로는 옳다 — 조향이 안 선 채로
구동하면 엉뚱한 방향으로 간다. 문제는 **그 상태가 무한히 지속돼도 아무도 보고하지 않는다**는 것이다.

⚠ **`turn`·`turn_reverse`·`spin` 은 이 결함이 없다.** 셋 다 Phase 0 에서 조향 도달을 기다리다
타임아웃하면 `status −3` + `abort()` 한다(`:162` · `:165` · `:219`).
`yaw_control` 만 Phase 0 목표가 **δ=0** 이라 대개 이미 충족돼 즉시 통과하고,
실제 조향 목표는 **주행 중 PID 가 만들어 내므로** Phase 0 에서 잡히지 않는다.

## Decision

### D1. `gate_blocked` **지속 시간**을 감시한다

주 루프에서 `gate_blocked` 가 참인 동안 시각을 누적하고, 임계를 넘으면 abort 한다.
거짓이 되면 누적을 리셋한다(순간 차단은 정상 동작이므로 무시).

```
gate_blocked 연속 지속 > yaw_control_gate_blocked_timeout_sec  →  abort(−8)
```

### D2. 임계 5.0 초 — **정상 조향 이동 시간보다 길게**

기동 시작이나 큰 헤딩 오차에서는 조향이 0 에서 목표까지 이동하는 동안 `gate_blocked` 가
**정상적으로** 참이 된다. 실측상 조향은 0→31° 이동에 약 3 초가 걸린다.
따라서 임계는 그보다 넉넉해야 오탐이 없다.

`steer_timeout_sec_`(5.0)와 같은 값을 쓴다 — 「조향이 목표에 닿는 데 허용하는 시간」이라는
의미가 동일하기 때문이다. 별도 키로 두어 조정 가능하게 한다.

### D3. 전용 status 코드 **−8**

`−3`(전역 타임아웃)에 얹지 않는다. 원인과 대응이 다르다 —
전역 타임아웃은 「느리다」이고, 이것은 **「조향이 지령을 실행하지 못한다」**로
`can_relay`/모터 쪽 점검이 필요하다. 로그에 지령각·실제각을 함께 남긴다.

### D4. `turn`·`spin` 은 손대지 않는다

이미 Phase 0 에서 같은 고장을 잡는다. 중복 장치를 넣지 않는다.

## Consequences

**얻는 것** — 조향 비응답이 **5초 안에** 전용 코드로 드러난다. 60초를 태우지 않고,
`status −3` 로 뭉뚱그려 보고되지 않는다.

**비용** — 주기마다 시각 비교 1회(무시 가능). 임계보다 오래 걸리는 정상 조향 이동이
존재하면 오탐(현 실측 3초 대 임계 5초로 여유 있음).

**⚠ 미해결로 남기는 것**
- 조향축이 **왜** 비응답이 되는지(`debt-051`)는 고치지 않는다. 본 ADR 은 **드러내기만** 한다.
- `yaw_control_reverse` 는 pose 토픽이 죽어 있어(`debt-050`) 별도 처리가 필요하다.
