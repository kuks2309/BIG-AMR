# ADR 2026-08-20 — 벽 티치 도구: 맵 사각 ROI 에서 직선 검출

- **Status**: Accepted — 2026-08-20 (사용자 지시: "티칭도구가 필요한데… 맵에서 직선 영역을
  정하는 것을 넣으면", "사각형 ROI 를 정하면 거기에서 직선 검출하면 어떨까")

## Context

- 상위 ADR(2026-08-18 벽 3면 정밀 측위)의 남은 위험 ②: 기준 벽의 수동 YAML 좌표는
  벤더가 명시적으로 경고하는 방식이다 — ANT(Autonomous Navigation Technology)는 기준
  직선을 **라이다 실측에서 학습(자동 맵핑)하고 사람이 선별(맵 정리)** 한다
  [ANT localization⁺ User Manual R2.6, §D 3.1 page 128 · §D 3.2 page 131], CAD 좌표는
  "Bad idea" [§D 3.2.2.2, page 132].
- 보유 Seer `.smap`(예: `map/260709_test.smap`, 17,711 장애물점, 해상도 0.02 m)은
  **라이다로 만든 맵**이라 같은 원칙을 충족하는 소스다. 파서 규칙: `normalPosList` 의
  생략 좌표는 0 (mcl2d_map 로더와 동일 규칙).

## Decision

`Tools/wall_teach/teach_walls.py` 신설 — **맵 위 사각 ROI 지정 → ROI 내 점으로 직선
검출 → wall_localizer 파라미터 YAML 자동 생성**.

- 적합: ROI 내 점의 총최소자승(주성분) 직선 + 3σ 트림 반복(가구·잡점 배제).
  끝점은 인라이어를 접선에 사영한 극값. 품질 게이트(점수·rms·길이 — 40 cm 은 ANT 준용)
  미달 시 경고.
- 모드 2종: ① 대화형(matplotlib RectangleSelector 로 드래그 지정) ② 비대화형
  (`--roi name:x1,y1,x2,y2` 반복 — headless 재생성·기록 재현용).
- **프레임 의미**: 이 경로로 만든 기준 벽은 **맵 프레임** 좌표다 → `station_frame: "map"`
  으로 출력하며 `/wall_pose` 는 맵 프레임 자세가 된다(mcl2d·도킹 목표와 좌표계 일치).
  현장 캡처(로봇 정차 스캔) 기반 스테이션 국소 티치는 후속 확장으로 남긴다.
- 산출물: 파라미터 YAML + 확인용 PNG(맵+ROI+적합 선분+rms).

## Consequences

- 이득: 기준 벽이 도면이 아니라 라이다 실측 유래 — 벤더 경고 해소. 재현 가능한
  비대화형 경로로 맵 갱신 시 재생성 가능.
- 비용: 도구 1본 + 인벤토리·이력 기록.
- 남는 위험: ① Seer SLAM 맵의 전역 왜곡은 벽 좌표에 그대로 들어간다 — 도킹은 반복
  정밀도(같은 벽 기준 상대 자세)라 영향 제한적이나, 절대 좌표 요구 작업은 주의.
  ② 대화형 모드는 headless 환경에서 검증 불가 — 실기 데스크톱에서 확인 필요.
