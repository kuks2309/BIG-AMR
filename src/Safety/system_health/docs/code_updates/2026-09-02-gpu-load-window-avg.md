# 2026-09-02 — GPU 사용률을 순간값에서 1초 창 평균으로 (sysfs.py)

## 무엇을

`read_gpu()` 의 부하 읽기를 단발 `_read_int` 에서 **1초 창 20표본 평균**으로 변경.
상수 `_GPU_LOAD_SAMPLES = 20`·`_GPU_LOAD_WINDOW_S = 1.0` 신설, `import time` 추가.
freq/max_freq 경로·`GpuInfo` 시그니처·JSONL 스키마 불변.

## 왜

T3-1 에서 yolo 6캠 배치 추론(약 100ms 가동/골 반복, 초당 5~7회) 중 GPU 가 실제로
일하는데(20Hz 직접 표본 평균 40.5%, 90% 초과 22/60) 대시보드 GPU 는 대부분 0.0% 로
표시됐다 — 5초 간격 순간 표본이 대부분 유휴 골에 떨어지는 **에일리어싱**. 온도·전류·클럭
상승과 모순되는 표시로 사용자 혼선 발생(2026-09-02, issues_and_fixes 동일 날짜 entry).
