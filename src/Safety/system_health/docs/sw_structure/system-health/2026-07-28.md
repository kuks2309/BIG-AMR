### 7. 시퀀스 — 표본 1주기

```mermaid
sequenceDiagram
    participant SD as systemd
    participant RUN as sampler.run
    participant SYS as sysfs
    participant TH as thresholds
    participant RL as ringlog
    participant JD as journald

    SD->>RUN: ExecStart (--interval 5 --out-dir ...)
    RUN->>SYS: read_cpu_times() (기준선, 기록 안 함)
    loop 정지 신호 전까지
        RUN->>SYS: collect() — 온도·CPU·메모리·디스크·팬 (+12주기마다 /proc 순회)
        SYS-->>RUN: record dict
        RUN->>RUN: record["log_write_failed"] = 직전 주기 결과
        RUN->>TH: evaluate(record, thresholds)
        TH-->>RUN: findings (OK 제외, 심각도 내림차순)
        alt out-dir 지정
            RUN->>RL: write(record)
            alt 기록 실패
                RL-->>RUN: RingLogWriteError
                RUN->>JD: stderr — ERROR + record 전문 덤프
            end
        else 미지정
            RUN->>JD: stdout — JSON 한 줄
        end
        opt findings 있음
            RUN->>JD: stderr — 심각도 + 사람이 읽을 경보
        end
        RUN->>RUN: _sleep_until(+interval)  ← 0.2초 단위로 정지 확인
    end
    SD->>RUN: SIGTERM
    RUN-->>SD: exit 0 (실측 0.21초)
```

### 구조 관찰 (결함 평가 아님 — code_review 소관)

- **판정과 수집이 분리돼 있다.** `thresholds.evaluate()` 는 record dict 만 받으므로 실장비 없이
  전 경로를 테스트할 수 있다. `dataset_collector` 의 `sampling.py` 와 같은 구조다.
- **가변 전역이 1개**뿐이고 그 writer 가 단일(신호 핸들러)이라 동시성 표면이 최소다.
