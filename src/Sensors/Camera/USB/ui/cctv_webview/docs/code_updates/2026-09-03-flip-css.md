# 2026-09-03 — 뒤집힌 장착 카메라의 CSS 180° 표시 (로스터 flip 연동)

## 무엇을

- launch: 로스터에서 `flip: true` 카메라를 뽑는 `_flipped_cameras()` 신설, `flipped_cameras`
  파라미터 주입(빈 목록은 [""] sentinel — rclpy 빈 리스트 타입 추론 불가).
- app.py: 파라미터 수신·sentinel 필터 → `make_server(flipped=…)` 전달 + 기동 로그.
- server.py: `_tile(flip=)`·`build_index_html(flipped=)`·`img.flip { transform: rotate(180deg) }`.
  원본 JPEG 바이트는 불변(MJPEG 패스스루 설계 유지) — 표시만 브라우저가 돌린다.
  검출 오버레이는 돌리지 않는다(yolo 가 정립 프레임 기준 좌표를 내므로 그대로 정합).

## 왜

T3-1 기체는 카메라 6대 전부 180° 뒤집힌 장착 — 스냅샷 판독으로 확정(보드 라벨
"1 cam_f" 등 4대 글자 역상 + lf/lr 바닥이 화면 상단). 카메라(UVC) 하드웨어에
flip/rotate 컨트롤 부재를 v4l2-ctl 로 확인 → 소스(픽셀) 보정 불가, 소비자 보정 채택.

## 검증

- 단위 테스트 18 PASS
- T3-1 배포·재기동: 대문 페이지에 `class="flip"` 6개 + CSS 룰 존재, 기동 로그
  "180° 회전 표시: 6대" — 스냅샷 180° 회전 결과 정립 확인(라벨 정상 판독)
