## 구조 (모듈 세트 추상화)

```
Twist ─▶ kinematics (DualSteer | DiffDrive) ─▶ ModuleCommand[{v m/s, θ rad|None}]
      ─▶ backend TongyiSdoBackend ─▶ CAN SDO (0x60FF / 0x607A+0x3F / guard RTR)
```
