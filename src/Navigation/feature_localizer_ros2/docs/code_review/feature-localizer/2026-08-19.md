## 1. 무엇을 만드나

스테이션 국소 정밀 측위: 라이다 스캔에서 직선(벽)을 추출해, YAML 로 정의한 기준 특징면 3면과
대응시켜 SE(2) 자세(x·y·yaw)를 최소자승으로 푼다(BlueBotics ANT 의 자연 특징 방식).
코어는 ROS 비의존(mcl2d_core 관례) — 합성 스캔으로 ctest 단위검증한다.

- 단위: 내부 m·rad 단일. 직선 법선형 `n·p = d`, `d ≥ 0`, `n` = 원점→직선 수직(원점 정향).
- 변환 표기: `T_a_b` — `p_a = T_a_b · p_b`. 출력 자세는 `T_station_base`.

## 7. 검증 기록 (2026-08-19, 이 장비 aarch64/gcc 11.4/Humble)

- 변이 검증: `solvePose` 병진 우변 부호를 고의 파괴 → 2/3 실패 확인 후 원복 → 3/3 PASS

- SIL 스모크: 합성 스캔(U자 스테이션, 참값 x=0.5 y=0.1 yaw=2°) → `/feature_pose`
  x=0.500035 y=0.099981 yaw=2.006° (오차 35µm·19µm·0.007°), 진단 OK·벽 3면 전부 대응
- 시나리오 시뮬레이션 8종(§6 킷, 20Hz·720빔): σ=10mm 에서 정지·주행·가림·클러터·초기오차
  모두 xy RMSE ≈3mm·yaw ≈0.09°·해율 ≥97.7%, 가림 시 DEGRADED 강등 정상.
