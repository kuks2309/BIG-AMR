# 입력 두절 워치독 이식 + SIL 빌드 차단 해소 (debt-106 · debt-105)

## debt-106 — 입력 두절 워치독

### 무엇을

`mcl2d_ros2` 에 스캔·오도 두절 감시를 얹었다. 원본 `MCLoc` 의 `ScanLostTimeThresh`·
`OdoLostTimeThresh` 에 대응한다.

| 파일 | 내용 |
| --- | --- |
| `include/mcl2d_ros2/lost_watchdog.hpp` | ROS 무의존 판정 클래스 `LostWatchdog` (신설) |
| `src/mcl2d_localization_node.cpp` | 타이머 감시 + `/diagnostics` 발행 |
| `test/test_lost_watchdog.cpp` | 회귀 8항목 (신설, ctest 등록) |

### 원본에서 그대로 옮긴 것

- 임계 기본 **300 ms**, 범위 **[0, 10000]** — 이 키는 원본의 어떤 설정 파일에도 없고
  300 은 바이너리 기본값이다
- 판정식 — 원본이 `임계 >= 경과` 를 정상으로 보므로 두절은 **초과**에서만 성립한다
- 두절 진입 시 **1회** 로그(원본의 정적 `err_reported` 플래그), 회복 시 해제
- 에러 번호 **52102**(스캔) · **52106**(오도)
- **발행을 막지 않는다** — 게이트가 아니라 워치독이다

근거: `docs/comparison/seer-libmcloc-odom_vs_mcl2d-port_2026-07-31.md` §8

### 우리 쪽 판단이 들어간 곳

- **에러 게시처**. 우리에겐 `rbk::ErrorCodes` 버스가 없어 `/diagnostics` 로 내보내고
  원본 번호를 key/value 로 남긴다 — 그 번호가 살아남는 유일한 자리다.
- **감시 구동 주체는 타이머다.** 오도 콜백에 얹으면 오도가 끊긴 순간 감시도 함께 멈춰
  정작 그 두절을 못 알린다.
- **기준선은 활성화 시각**이다. 원본이 그 시각 슬롯을 언제 세우는지는 실측 기록에 없다 —
  활성화 시각으로 잡아야 **한 건도 오지 않는** 경우도 두절로 잡힌다.
  `ever_received` 가 「끊김」과 「처음부터 없음」을 가른다.

### 검증

- 회귀 8항목 통과 · `colcon test` 1/1
- **돌연변이 8/8 검출** — 경계 완화 · ms→ns 환산 누락 · 진입판정 제거 · 회복 제거 ·
  클램프 제거 · 무수신 은폐 · 기본임계 변경 · 에러번호 훼손
  - 「기본임계 변경」이 처음엔 **미검출**이었다. 시험이 상수를 **상수 자신과** 비교하고
    있어 값을 바꿔도 통과했다 — 원본 값을 리터럴로 못 박아 닫았다
- **실기동**(청정 도메인): 무입력 → 둘 다 ERROR `no input received` ·
  오도 인가 → OK + 회복 로그 1회 · 오도 절단 → `input lost` ·
  두절 로그는 진입당 1건(전 구간 2건)
- **게이트가 아님을 실증**: 스캔을 끊은 상태에서도 `/mcl_pose` 가 **19.999 Hz** 로 계속 발행

## debt-102 — 슬립 감지 전제

슬립 감지를 **성립시키지는 못했다.** 그러려면 휠 오도가 있어야 하고, 그건 조향 부호
확정(`debt-004`·`debt-007`) 뒤의 일이다. 대신 **깨진 전제를 조용히 두지 않게** 했다.

`odom_source` 파라미터(`wheel`|`laser`, 기본 `laser`)를 신설했다:

- 값이 둘 중 하나가 아니면 configure 실패 — 오타로 조용히 넘어가지 않는다
- `wheel` 이 아니면 기동 시 WARN — 「판정은 계속 계산되지만 근거로 쓰지 말 것」
- `/diagnostics` 에 `skid_detection: degenerate (laser vs laser)` 상시 노출

그 과정에서 **코어가 매 주기 판정하는 `reportState()` 를 노드가 꺼내지도 않고
버리고 있었다**는 것을 확인해 함께 노출했다(`report_state`·`confidence`).

실기동: 잘못된 값 → 종료코드 1 + FATAL · `laser` → WARN + degenerate ·
`wheel` → WARN 0건 + valid.

## debt-103 — 기존 주석을 훑는 검사기

`Tools/comment_check/scan_gate.py` 를 신설했다. 게이트 훅은 **이번에 추가된 텍스트만**
보므로 이미 들어가 있는 주석은 아무도 훑지 않는다 — 그 구멍을 메운다.

판정 규칙을 **훅에서 직접 불러 쓴다.** 복사해 두면 훅이 바뀌는 순간 조용히 어긋나
「통과」를 근거로 쓸 수 없게 된다. 계약 시험(`test_scan_gate.py`)이 훅을 임시로
무력화해 도구 판정이 따라 바뀌는지 확인하므로, 복사본으로 회귀하면 시험이 깨진다.

⚠ 이 세션 중 임시로 쓰던 사본은 훅에 **없는** 서술어(`종전` 등)를 더 갖고 있었다 —
그 사본이 잡은 위반 일부는 실제 게이트로는 위반이 아니다. 정식 도구는 훅과 같다.

실측 기준선: `src`+`Tools` 736파일에 **위반 633건**(게이트 동일 모드).

**존치**: 이 저장소에는 pre-commit·CI 가 없어 여전히 수동 실행이다.
