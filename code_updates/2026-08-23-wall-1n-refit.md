# 2026-08-23 — 벽 대응 1:N + 원시 점 회랑 재적합 (정밀도 6배 개선)

> 약어: RMSE(Root Mean Square Error) · TLS(Total Least Squares)

- 사용자 판정: "일반적인 2d localization 보다 성능이 나쁘다니... 이건 아니잖아" ·
  "직선의 방정식만 정확히 구하면 정밀도는 이미 보증된 방법인데" — 정확한 지적이었다.
  3직선→자세 폐형 해는 문제가 없었고, **직선 방정식을 점의 40%(토막 1개)로 구하던
  앞단이 전부**였다.
- 사전승인: `docs/adr/2026-08-23-wall-1n-point-refit.md`

## 변경 (wall_localizer_core)

- `matchWallsMulti` 신설 — 게이트 통과 선분을 벽당 여러 개 귀속(1:N), 겹침은 구간
  합집합/예측 벽 길이. 시드선(점수 최대 토막)·관측 구간을 묶음에 보존
- `refitWallFromPoints` 신설 — **관측 시드선** 중심 회랑(±`refit_corridor_m`) ×
  접선 구간(토막 관측 구간 ∪ 예측 전장 + margin)의 원시 점 전체를 TLS 재적합,
  1패스 후 결과선으로 재중심화해 2패스. 결과가 예측과 각도 게이트 이상 벌어지면 기각
  - 개발 중 결함 2건을 시뮬로 잡아 수정: ① 회랑 중심을 예측선으로 두면 초기 추정
    오차(대응 게이트 0.3 m)가 회랑 폭(cm)을 넘어 벽 점이 회랑 밖 — 시드선 중심으로 교체
    ② 접선 구간을 토막 관측 구간만으로 한정하면 커버리지 낮은 스캔에서 점 손실 —
    예측 전장과 합집합으로 확장
- 파사드 `update`: matchWalls(1:1) → matchWallsMulti + refit 경로로 교체 (해석기 무변경)
- 파라미터 신설: `refit_corridor_m`(0.06) · `refit_margin_m`(0.10) — YAML·노드 선언 동반

  점수 ≥140 — 토막화 면역을 직접 단정). 변이 검증: 회랑 중심을 예측선으로 되돌리면
  test_wall_localizer 실패 → 원복 3/3
