## SIL 이 잡은 설계 결함 2건 (수정 완료)

1. **속도차 yaw 무권한**: 코어 `composePhase4Wheels` 의 w_deg(속도차 yaw)는 조향 ≈ ±90°
   (측면 crab — LGIT 원 기체 구성)에서만 유효. 전방 접근(조향≈0)은 sin(조향)≈0 이라
   무권한·부호 불안정 — 1차 실행에서 **yaw +17° 폭주, runaway 방어선(이식 코어)이 정지**
   시킴(방어선 실증). → 조립 층에서 **전/후 조향 분할**(δf=steer+δh, δr=steer−δh,
   ω≈v·δh·cos(steer)/arm, 후진 시 부호 반전)로 교체. 코어 무수정 유지.
2. **yaw 미달 행**: 접근 중 조향 분할의 yaw 권한은 v 에 비례 → 정지 근방에서 소멸,
   완료 게이트(3축)를 영원히 못 넘는 행 발생. → **PRE_YAW 페이즈** 신설(접근 전 제자리
   회전으로 초기 yaw 소거 — 조향 ±90° 전환은 settle-then-drive 2 s, 정본 지식) +
   행 방지 가드(d·lat 수렴 + yaw 미달 지속 시 VERIFY 로 정직 판정 이관).

부수 수정: SIL 러너가 시나리오 시작 자세를 wall_localizer 초기 추정으로 전달(실운용에선
