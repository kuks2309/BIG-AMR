# 2026-08-23 — 실기 1차: 판+좌측 벽 정지 반복정밀도 (서브밀리미터)

> 약어: RMS(Root Mean Square) · TF(Transform)

- 사용자 지시: "장애물을 놓고 한번 테스트 해 보자" → "판을 가져다 두었음" →
  "벽은 전방에 위치 왼쪽에 위치함" (판=전방, 벽=좌측)
- 구성: 기존 측위 체인 재사용(중복 기동 없음 — sick 전·후 + dual_laser_merger 가동 중
  확인 후 `/scan_merged` 구독). 시험 노드는 wall_localizer 1개만 추가 기동, 종료 시 정리.

## 실기 확인 사항

- `/scan_merged` 는 base_link 와 **항등 TF** — 시험은 merged 로 수행.
  ⚠ `/scan_front` 원시 프레임은 **뒤집힘 장착(roll=π, yaw −45.6°)** — 우리 노드의 평면
  yaw 추출이 틀리는 구성이므로 front 원시 토픽 직결은 금지, merged 사용이 정석.
- 발행자 중복 점검 함정: `ros2 topic info -v | grep -c 'Node name'` 은 **구독자까지
  센다** — 발행자 수는 PUBLISHER 절만 세어야 한다(초기 4/6/2 오판 → 실제 각 1).
- **실기 SICK 거리 잡음 σ ≈ 2 mm** (판·벽 직선 적합 rms 1.8~2.0 mm, 5스캔) —
  σ=30 mm 가정 시뮬레이션보다 15배 좋음. 기본 파라미터(임계 0.03=15σ)로 충분.

## 티치·구동

- 티치: `/scan_merged` 5장에서 판(끝점 (3.48,−0.68)-(3.54,0.31), 0.99 m)과
  좌벽((−1.98,4.02)-(3.09,3.75), 5.08 m)을 적합 — 스테이션 프레임 = 티치 시점 base_link.
  직교 2면이라 가관측성 충족(normal_spread 실측 0.23).
- 구동: `wall_localizer_node` + `-r scan:=/scan_merged`, TF 자동(항등 확인 로그).
