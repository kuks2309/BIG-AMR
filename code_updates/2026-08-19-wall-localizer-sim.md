## 사고와 교정 — 1차 실행 전량 무효

1차 실행에서 시나리오별 `kill $node_pid` 가 **`ros2 run` 래퍼만 죽이고 실제 노드가
생존**해, 시나리오가 지날수록 측위 노드가 누적됐다(S2 에서 해 수가 스캔의 1.96배 →
S6 에서 5.4배 — 동일 스캔에 발행자 여러 개). ros2 도메인 §5 가 경고하는 다중 발행자
오염과 동일 형태라 **1차 수치는 전량 무효 처리**하고, 스크립트를 실행 파일 패턴
`pkill`/`pgrep` 기반으로 교정(시나리오 시작 전 프로세스 수 1 확인·종료 후 0 확인) 후
전량 재실행했다.

관찰:

- 실사용 잡음대(σ=10mm)에서 정지·주행·가림·클러터·초기오차 모두 **RMSE 3mm 내외·
  yaw 0.09° 내외**, 해율 ≥97.7%. 가림 시 쓰레기 자세 대신 DEGRADED 강등이 설계대로 동작.
- 클러터의 적대 사례(좌측 벽 앞 0.3m 평행 판재 — 대응 거리 게이트 경계값)도 오인 없음.
- **σ=20mm 는 기본 파라미터의 경계 밖** — split_dist_m(0.03)가 잡음 3σ(0.06) 미만이라
  벽이 토막나 LOST 산사태. split_dist_m·max_dist_residual_m 를 잡음 3σ 로 올리면 94.7%
  회복(정밀도는 8.4mm 로 하락). → **실기 튜닝 지침: 현장 SICK 거리 잡음 σ를 실측해
  split_dist_m ≈ 3σ 로 설정**할 것. config 주석에 원칙 기재됨.
- 남는 한계: 시뮬레이션은 가우시안 거리 잡음만 모사 — 실 라이다의 반사율 의존 바이어스·
  혼합 화소(mixed pixel)·다중 반사는 실기 검증 항목.
