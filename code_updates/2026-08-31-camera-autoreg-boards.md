# 2026-08-31 — 카메라 자동 등록: ChArUco 보드 생성(1단계) + 인식·매핑·규칙 생성(2단계)

요구(사용자): 카메라 자동 등록을 위해 전방=1, ROS2 좌표계처럼 반시계로 6번까지
마커를 놓고 인식하는 체계 — 초기 설정·USB 규칙의 근거. 우선 마커 1~6 생성.

사용자 결정 3건: ① 번호 규약 전방=1·반시계 ② 단일 ArUco 대신 **ChArUco**(식별+캘리브레이션
겸용) ③ 기존 캘리브레이션 자산(`Tools/CameraCalibration/make_charuco_pdf.py`) 활용.

## 신설 — `Tools/camera_autoreg/`

- `generate_boards.py` — ChArUco 6×6칸·30mm(외곽 180mm, A4)·`DICT_5X5_1000` 보드 6장을
  실치수 PDF 로 생성(100% 인쇄 시 칸 30mm, 100mm 스케일바·큰 번호 라벨).
  `make_charuco_pdf.mm_to_px` 재사용.
- **보드별 고유 마커 ID 대역**: 보드 n = `500+(n-1)*20 .. +17`. 기존 캘리브레이션 보드
  6종이 전부 ID 0 시작(최대 ~84)이라 그대로 쓰면 보드 구분 불가 + 시야의 캘리브레이션
  보드가 위치로 오인됨 → 500 오프셋으로 완전 분리(생성 중 자가 발견·수정).
- 역산 단일 근원 `board_number_from_marker_id` — 2단계 인식 스크립트가 import 예정.
- 산출물 `boards/board_{1..6}_{cam}.pdf` 6장.

## 검증

- 자가 검증 PASS: 6보드 × 마커 18개 전수 재검출(CharucoDetector)·ID 대역·역산 일치.
- 경계 검증 PASS: ID 0..119→무소속(0), 500..517→1, 600..617→6, 대역 여유분(518 등)→0.
- PDF 육안 확인: 보드·라벨(`1 cam_f`)·스케일바 정상.

## 2단계 — `register_cameras.py` (같은 날 오전 구현)

사용자 확인: 인식 → 위치 선정 → udev 규칙 구축까지. 추가 요구: **시리얼을 직접
읽을 것** — 시리얼이 개체 영속 키이며 향후 시리얼별 내부 캘리브레이션 파일 매칭
예정(미구현).

- 프레임 소스 2종: 기본 `topics`(구동 중 퍼블리셔 구독 — 장치 EBUSY 회피, 로스터가
  틀려도 이름↔시리얼 대응만 사용) / `--source device`(by-id 실스캔으로 시리얼 직접
  판독 — 신품·교체 카메라 경로, usb-cam@ 활성 시 중단 안내).
- 판정: 프레임별 마커 득표 → 최다 보드(임계 3표·동률 무효). 미검출·중복·누락은
  오류 목록 + `--apply` 거부.
- 산출: `out/camera_common.proposed.yaml`(주석 보존 표적 치환, `--apply` 시 백업 후
  갱신) + `out/99-amr-cameras.rules`(`ATTRS{serial}`→`/dev/camera/<위치명>` 심링크,
  설치는 sudo 사용자 몫).
- `ATTRS{serial}` 실기 확인(udevadm: AY4EC5401F4 노출 OK).

  경계(임계/동률)·매핑 오류 3종·udev 텍스트·로스터 치환(주석 보존·항등 무변경).
