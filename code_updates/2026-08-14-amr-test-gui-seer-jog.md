## 무엇이 문제였나

제어권(intercept)이 없으면 버스는 Seer 가 쓴다. 그 상태에서 조그 버튼을 누르면
`조그 불가 — 제어권을 먼저 획득하세요` 로 **거부만 하고 끝났다.** 실기에서 로봇을
움직여 보려면 매번 제어권을 잡아야 했다.

## 무엇을 바꿨나

`_jog` 가 제어권 유무로 갈라진다.

| 상태 | 경로 |
| --- | --- |
| 제어권 보유 | 종전 그대로 — CAN 직결(구동 0 → 조향 → 정착 확인 → 구동) |
| 제어권 미보유 | **Seer 개루프 운동 2010**(`vx`, `vy`) 재송신 |
| `정지` | 보유 시 구동 0 / 미보유 시 **Seer 2000** |

Seer 클라이언트는 GUI 가 이미 상태 폴링에 쓰는 `RobokitClient` 다. 제어 포트(19205)는
배타 포트라 상태 폴링과 **별개 연결**을 만든다(`_seer_ctrl_client`).

### 부호 규약은 새로 만들지 않았다

`JOG` 표는 CAN 경로용이라 (조향각, 구동 raw 부호)로 적혀 있다. 같은 운동을 차체 속도로
옮기는 식은 표의 **실측 앵커 두 개에서 그대로 도출**된다:

```
v = −raw_sign × (cos θ, −sin θ)      # θ = 조향각
  조향 0° · raw 음수 → (+1, 0)  = 전진(+x)   ← 실측 앵커 ①
  조향 +90° · raw 양수 → (0, +1) = 좌(+y)    ← 실측 앵커 ②(IMU 실증)
```

8방향 환산 확인(속도 입력 50 mm/s):

| 방향 | vx | vy | 방향 | vx | vy |
| --- | --- | --- | --- | --- | --- |
| 전진 | +0.050 | −0.000 | 좌전 45° | +0.035 | +0.035 |
| 후진 | −0.050 | +0.000 | 우전 45° | +0.035 | −0.035 |
| 좌 크랩 | −0.000 | +0.050 | 좌후 45° | −0.035 | +0.035 |
| 우 크랩 | +0.000 | −0.050 | 우후 45° | −0.035 | −0.035 |

속도는 GUI 의 `바퀴 속도`(mm/s) 입력을 m/s 로 환산한다.

## 안전 — 시한 있는 지령

2010 은 `duration` 안에 새 지령이 없으면 스스로 멈춘다. 그 성질을 정지 수단으로 쓴다:

- `SEER_JOG_DURATION_MS = 600` — 지령에 실어 보내는 시한
- `SEER_JOG_PERIOD_S = 0.2` — 그보다 짧게 재송신해 속도를 유지

⇒ **정지를 누르거나 GUI 가 죽으면 재송신이 끊겨 0.6초 안에 로봇이 선다.** 워커가 끝날 때는
`stop_motion()`(2000)도 반드시 보낸다.

## 남는 것

- **manual 모드 요구**: 우리 `seer_api` 패키지 docstring 은 2010 을 「manual 모드 전용」이라
  적는다. 자동/작업 모드에서의 거부 코드는 실기에서 확인해야 한다.
- 회귀 없음 — Seer 경로는 네트워크 의존이라 대역 없이는 시험할 수 없다. 환산 함수
  `_seer_velocity` 는 순수 함수이므로 시험을 붙일 수 있다(미작성).
