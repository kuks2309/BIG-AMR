## ① Seer 대조 — 굳은 값 비교 제거 (`app.py:520`)

**제어권을 쥐면 Seer 는 모터를 못 읽는다**(릴레이가 intercept 로 넘어가 판독이 굳는다).
그런데 대조 중단 조건이 「제어권 보유」가 아니라 「우리가 조향을 보냈는가」였고 그 플래그는
제어권을 잡을 때 다시 열렸다. 게다가 대조를 부르는 지점이 폴링 중, 즉 제어권 보유 중에만
도니 **유효한 창이 애초에 없었다**.

대조 상대를 **잡기 직전에 읽어 둔 Seer 각도**(`_seer_at_take`)로 바꾸고, 비교 대상은 **획득
후 처음 들어온 신선한 CAN 실측**으로 한정해 **축별 세션당 1회**만 본다.
죽은 상수 `SEER_MATCH_STREAK`·`SEER_MATCH_REWARN_S` 와 연속 카운터 상태 2개도 제거했다.

근거는 단독 GUI 실기 로그다 — 제어권 획득 1초 뒤, 아무도 축을 안 움직였는데 45° 불일치
경보가 났고(11:16:03), 같은 수정 뒤 재획득에서는 경보가 없었다(11:32:51).

## ② 제어권 없을 때 Seer API 조그

제어권이 없으면 버스는 Seer 가 쓴다. 그 상태의 조그를 백엔드가 거부하는 것으로 끝내지 않고
**Seer 개루프 운동(2010)** 으로 보낸다.

```
1060 소유자 조회 → 4005 제어권 획득 → 2010 재송신 → 2000 정지 → 4006 반납
```

⚠ **4005 는 기존 소유자의 제어권을 뺏는다.** 없으면 2010·2000 이 `ret_code=40020`
(`control is preempted`)로 거부되므로 필수다. 반납해도 원래 소유자에게 자동 복귀하지 않는다.

**부호 규약은 새로 만들지 않았다** — `JOG` 표(조향각, 구동 raw 부호)에서 도출한다:

```
v = −sign × (cos θ, −sin θ)
  조향 0° · raw 음수 → (+1, 0)  = 전진(+x)
  조향 +90° · raw 양수 → (0, +1) = 좌(+y)
```

8방향 환산 확인(50 mm/s): 전진 `+0.050/−0.000` · 후진 `−0.050/+0.000` ·
좌 크랩 `−0.000/+0.050` · 우 크랩 `+0.000/−0.050` · 대각 4방향 `±0.0354/±0.0354`.

**시한 있는 지령이 정지 수단이다** — 2010 에 `duration` 600 ms 를 실어 200 ms 마다 갱신한다.
정지하거나 GUI 가 죽으면 재송신이 끊겨 0.6초 안에 로봇이 선다. 워커 종료 시 2000 도 보낸다.

## ③ 중복 실행 가드 (`gui_node.py`)

`flock(LOCK_EX|LOCK_NB)` 로 한 번에 하나만 띄운다. **단독 GUI 와 같은 잠금 파일**
(`/tmp/amr_test_gui.lock`)을 쓰므로 둘 중 어느 쪽이든 이미 떠 있으면 다른 쪽이 뜨지 않는다 —
판다는 한 프로세스만 열 수 있고, 두 창이 동시에 USB 를 잡으면 둘 다 못 쓴다.

`flock` 인 이유: 프로세스가 죽으면 커널이 자동으로 푼다. PID 파일만 두면 비정상 종료 뒤
찌꺼기가 남아 다음 실행을 영영 막는다.
