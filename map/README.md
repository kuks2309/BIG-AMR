# `map/` — Seer `.smap` 보관 규약

**파일은 맵 이름당 하나다.** `260709_test.smap` 이 정본이며 **로봇에 로드된 현재 맵과 같아야 한다.**
날짜·md5 를 붙인 사본을 옆에 두지 않는다 — 2026-09-05 에 정본이 로봇 맵과 다른 내용을 담은 채
사본 3개와 공존해, 시각화가 실재하지 않는 스테이션 4개(LM1~LM4, 좌표 상이)를 그렸다.
이력이 필요하면 git 이력에서 꺼낸다.

## 갱신·검증 절차

```bash
python3 Tools/seer_map/download_map.py <출력디렉터리>   # 1300 로 현재 맵 조회 → 4011 다운로드 → md5 대조
```

`로봇 보고 md5 == 계산 md5` 가 뜨면 그 파일로 `map/<이름>.smap` 을 덮어쓰고 커밋한다.
md5 를 문서에 적을 때는 **관측 시각을 함께** 적는다 — 맵은 현장에서 갱신되므로 값이 바뀐다.

| 관측일 | `260709_test` md5 | 스테이션 |
|---|---|---|
| 2026-09-05 | `0319831dcda7838484a20d1a8bb62487` | LM1(−3.743, 13.931) · LM2(−10.000, 13.931) |
